## 最新: R3.1（ガチャ料金テスト無料化）
- **テスト中は通常／年代別／高級の有料ガチャをすべて無料化**。手持ち現金が0 Gでも引ける。所持金を減らさず、入手品・図鑑・累計回数・保証カウンターは通常どおり更新。
- 本来の価格（通常800 G/回、年代別10,000 G/回、高級650,000 G/10連）は参考表示として保持。`index.html` の `TEST_FREE_GACHA` を `false` に戻せば徴収処理へ切り替え可能。

## R3の変更履歴
- 通常ガチャは10回以内にSR以上1個保証。高級ガチャは**650,000Gの10連専用でUR以上1個確定**。ほか9枠は通常確率
- 開封→順番に鑑定→10連結果一覧（iPhoneは2列×5行で一画面表示を目標・スキップ可）
- アイテム詳細画面。現在価格、品質、過去24時間の価格推移、6時間・12時間後の参考価格
- 所持品の入手順／評価額順／レアリティ順／分類順。分類とレアの独立フィルター
- 図鑑でもレア・分類・基準価格・番号でソート、未発見はシルエット表示
- 個別・一括売却時、**現金は売却額分増加、所持アイテム評価額は同額減少**。売却直後の総資産（現金＋アイテム）は一定。発見図鑑は維持
- 重複・高騰品の売却アシスト、保護、複製、ジャンル別相場、ニュース
- HOMEの資産推移は総資産・アイテム資産・現金・日別利益の4タブ。日別利益は純資産変化（売却代金≠利益）
- 20種類の仮画像をHTMLに内蔵。新規画像の大量生成は開発後半

## セーブについて
- R3で通常ガチャ天井・日次履歴フィールドを追加。旧セーブはそのまま利用可能
- R1と同じlocalStorageキー `treasure-exchange-demo-r1` / `v:1` を継続。R1のセーブデータをそのまま利用。
- セーブはブラウザ単位で、端末間同期や本番用サーバー権限は未実装。
- ブラウザのデータ削除等で消えることがあるため、試作中の所持品に恒久保証はない。
