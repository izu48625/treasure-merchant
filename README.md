# 時空の財宝商会 — Treasure Merchant

iPhone Safariを主対象とした収集・相場・資産運用ゲームの初期プロトタイプ。

## R1の起動
- [index.html](./index.html) をブラウザで開く。20種の仮画像・CSS・JavaScriptを内蔵した単一ファイル。
- ガチャ、図鑑、所持品、個別/一括売却、複製、相場、総資産表示を体験できる。
- 広告ボタンはデモ。**実際の広告、課金、共有市場サーバーは未接続。**
- セーブは同じブラウザのlocalStorageに保存。データ同期・端末間移行は未対応。
