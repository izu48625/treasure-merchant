# 時空の財宝商会 — Treasure Merchant

iPhone Safariを主対象とした財宝収集・相場・売却ゲームのWebプロトタイプ。

## プレイURL
**https://izu48625.github.io/treasure-merchant/**

GitHub Pages / main / rootの`index.html` を配信。デモは無料で、実際の広告視聴や課金はありません。

## 最新: R2
- 初回無料10連、通常/年代別/高級ガチャ。開封→順番に鑑定→10連結果一覧（スキップ可）
- アイテム詳細画面。現在価格、品質、過去24時間の価格推移、6時間・12時間後の参考価格
- 所持品の入手順／評価額順／レアリティ順／分類順。分類とレアの独立フィルター
- 図鑑でもレア・分類・基準価格・番号でソート、未発見はシルエット表示
- 個別・一括売却時、**現金は売却額分増加、所持アイテム評価額は同額減少**。売却直後の総資産（現金＋アイテム）は一定。発見図鑑は維持
- 重複・高騰品の売却アシスト、保護、複製、ジャンル別相場、ニュース
- 20種類の仮画像をHTMLに内蔵。新規画像の大量生成は開発後半

## セーブについて
- R1と同じlocalStorageキー `treasure-exchange-demo-r1` / `v:1` を継続。R1のセーブデータをそのまま利用。
- セーブはブラウザ単位で、端末間同期や本番用サーバー権限は未実装。
- ブラウザのデータ削除等で消えることがあるため、試作中の所持品に恒久保証はない。
