# R4.3 — 商会遊技場（試作）

更新: 2026-10-23

## 実装
- ホームから「商会遊技場」へ入る（画面タブ4種）。
- 財宝勝負：複数種類・複数品質・複数個の財宝投入。投入基本金額の合計 / 目標財宝の基本金額 × 90%（最大90%）で成功判定。複製品は基本金額の45%相当。相場変動と品質は抽選確率に影響しない。成功時は目標財宝1点を追加、失敗時は追加なし。**勝敗に関係なく投入品を消費**。履歴・図鑑情報は維持し、所持品だけ削除。
- 初期の財宝保護・お気に入り全種類は投入候補から自動除外。勝負前に消滅の確認ダイアログ。画面は50組ずつの表示、選択中は常時表示。
- 無料財宝チャレンジ：1日1回。基本金額1,000G相当から計算、成功率の上限30%。選択アイテムを1点獲得するか、何も得ない。日付 `arcadeFreeDay` を既存セーブ内に追加。試作では端末日付とテスト用の時間進行に依存。
- 商会ルーレット：Gを賭け、ハズレ40%、1倍G 27%、1.5倍G 18%、2倍G 9%、3倍G 4%、ガチャ権利1.5%、財宝0.5%（該当財宝候補なしで2倍G）。
- 商会スロット：3リール×5絵柄各等確率。3つ異なる48%はハズレ、2つ一致48%は1.25倍G、同一絵柄3つ（合計4%）で特別報酬5種。特別報酬はG（4/8/15倍）、ガチャ権利、財宝。
- ゲーム内Gは外部通貨に交換できず、財宝・ガチャ権利は換金・譲渡不可の仮想アイテム。
- 抽選処理は端末内。利用可能なら `crypto.getRandomValues`、非対応端末は `Math.random` を利用。オンラインランキングで採用する際はサーバー確定が必須。

## 経済バランス・開発上の注意
- ガチャテストモード `TEST_FREE_GACHA=true` は従来どおり。プレイ中は無料・回数無制限で、遊技場から得たガチャ権利は蓄積するが消費されない。
- 景品の価値と払い戻しは暫定設定。既存の財宝20品目によって、ルーレット／スロットの財宝抽選候補は限定される。
- 遊技場の抽選では `state.draws` と周期保証カウンターは進めない（通常ガチャとは別扱い）。
- `v:1`、IndexedDB v2、旧セーブ、R4.1リーグ、R4.2図鑑、ガチャ抽選率は維持。

## QA
- 新規セーブで起動、ホーム・遊技場の描画、旧データ形式のJSON検証を通過。
- N/C品15点を投入して外れた場合の所持品消滅・図鑑永続登録を確認。
- 品質別の複数グループをまとめて成功した場合、対象2点消滅・賞品1点付与・旧図鑑履歴保持を確認。
- 無料挑戦の同日二重付与防止、ルーレットのハズレ時G減額、ガチャ権利・財宝の当選、スロット3一致の配当、G不足時の停止、セーブJSON構造の維持を模擬実行で確認。
- 未検証：iPhone Safari実機の描画・操作、IndexedDB非同期保存負荷、大規模な持ち物に対するパフォーマンス、統計シミュレーションによる経済バランスの調整。
