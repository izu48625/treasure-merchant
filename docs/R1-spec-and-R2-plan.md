# 時空の財宝商会｜R1実装仕様・R2計画
更新：2026-10-20

## R1の目的
20種類の画像を使って、収集・相場・売却の核となる体験を評価する。新規画像の大量生成はゲーム基盤ができるまで保留。

## ファイル
- `index.html`：単一HTML（CSS/JS/20種類の画像を内蔵）。サーバー・API不要のオフラインデモ。
- `data/items-r1.json`：20種類の画像を除くアイテムデータ（ID、レアリティ、分類、基準価格）。
- 正式画像管理表： https://docs.google.com/spreadsheets/d/19i4YpqR37h6scKFESuhHTysXPLi74NElfcM1A6kpcHM/edit （20点画風テスト）

## 現在の実装
### アイテム
- 20種類。レアリティ7段階 N/C/R/SR/SSR/UR/EX。
- 品質4段階：低70%・中100%・高160%・最高280%の価格補正。
- 図鑑は永続発見記録。売却しても発見歴は消えない。
- 所持品は個体別管理（ID、品質、保護、複製フラグ、獲得日時）。

### ガチャ
- 通常：800G/回。N60%/C27%/R10%/SR2.5%/SSR0.45%/UR0.045%/EX0.005%。
- 年代別：10,000G/回、現代以外を優先する試作フィルタ。
- 高級：50,000G/回、SSR等高レア寄り。
- 初回無料10連、試作専用の「デモ広告報酬で通常10連」。実際の広告・決済なし。
- 排出率と価格帯はプロトタイプ用で未確定。

### 相場
- 5大カテゴリ：現代・生活／歴史・武具／宝石・宝飾／骨董・道具／神話・伝説。
- 毎時算出。分類指数・個別指数・9時間ごとの高騰イベントの組み合わせ。
- ログアウト期間も、時刻から現在価格を再計算する方式。
- 6時間・12時間先の参考予報、テスト用の1時間早送り。
- **注意**：すべて端末内の仮市場で、他プレイヤーと共通の価格ではない。正式版ではサーバー確定相場へ移す。

### 売却と複製
- 個別売却、重複品候補抽出、高騰中候補抽出、選択一括売却。
- 保護品は売却不可。重複品選択は原則1種類につき最高品質の1個を残す。
- 複製1日1回、失敗しても原本を維持、複製品評価額45%、再複製不可。

### 資産と保存
- 現金・評価額はBigInt整数管理（ゲーム上の上限なし）。
- 保存はブラウザ内 localStorage。ブラウザ設定やプライベートモードでは保存できない可能性があり、端末間の同期もない。デモ用途のみ。
- 保有件数の大規模化は未対応。5,000種類＋大量の所有個体に向けてIndexedDBなどに置き換える。

## R1テスト結果
- JavaScript構文検査：通過。
- Chromium / 393×852 のモバイル幅で確認：ホーム→初回10連→所持品→重複抽出/売却→図鑑→市場1時間早送り→ホームまで動作。
- ブラウザのJavaScript実行エラーなし。
- 注意：テスト用の匿名/制限ブラウザ環境では localStorage が使えず、保存永続化については通常のSafari/HTTP(S)配信での追加テストが必要。

## R2の優先度
1. **資産と相場の頑健性**：1000人×365日シミュレーション。価格変化の上限、ガチャ期待値、複製の費用対効果を検証。資産上限は設けない。
2. **売却UX**：重複保護、品質保護、グループ別売却、複数条件、合計利益プレビューの改善。
3. **ガチャ演出**：高レア排出時の段階的な開封演出。通常操作では演出スキップも提供。
4. **大規模データ基盤**：5,000種類以上、入手個体の索引、仮想スクロール、画像遅延ロード、IndexedDB。
5. **共通相場のバックエンド設計**：決定的シード、時刻、価格検証のサーバー側権限。デモでは未接続。
6. **iPhone Safari実機QA**：画面幅、タップ領域、ロード速度、オフライン起動、保存と復元。
7. 追加画像生成は**上記の基盤実装後**に本格化する。

## 公開・権利
20種のうち後半15種は一覧画像から切り出した仮画像。文字やトリミングの残りを含む可能性がある。正式リリース前に高解像度・文字なしで個別に再生成・検査する。
