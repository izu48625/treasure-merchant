# R5.33 — Tiled屋内マップを探索本編の選択肢として統合

## 実装
- 既存のR5.30施設を **mapVersion:4** で維持。新Tiled屋内マップを **mapVersion:5** として追加し、探索準備画面でV5/V4を選択。
- V5の元データは `maps/indoor/indoor.tmj` と96タイルのR5.32アトラス。等倍タイルを3倍のワールド座標でドット絵描画（2304×1824ワールドpx）。
- 11物資（黄4/青5/紫2）を固定の配置で生成し、開封前に出撃単位でアイテム抽選を確定。実際のレア度は確率抽選。壁越しに調べることはできない。
- 本編の装備7枠、手動攻撃/自動攻撃、通常/高速/重装敵、敵の視認・追跡、戦利品、重量、2枠の安全ポーチ、5分制限、西側固定脱出口、成功決済、死亡/時間切れ/途中撤退ロストを使用。
- Tiledの床/家具/壁から物理衝突と敵の視線遮断を取得。Tiled敵6体を既存敵AIの固定巡回ポストとして利用し、従来の増援処理も適用。入り口・出口・物資地点・敵配置はTiledオブジェクトから読み取る。
- V5の途中セーブを **独立した地形番号5** で保存。地形データの非同期読み込み中はV5のセーブを不正として消去せず、復元を待つ。既存V1〜V4のチェックポイントとマップは変更しない。
- V5の保存コンテナは位置/種類/ID/品質種別/品目の妥当性を検査。すでに確定済みの戦利品を読み込み時に再抽選しない。
- R5.32の独立試遊 `maps/indoor/demo.html` は削除せず残す。
