# R5.21 — 一体型施設の戦闘体感・重量バランス改善

## 今回の狙い
R5.20の敵3種類と一体型施設は維持し、戦利品を持ち帰る駆け引き・壁を使った回避・手動攻撃の意味を強める。旧マップ・資産・抽選・セーブ形式には影響を与えない。

## 変更（mapVersion: 4のみ）
1. **重量超過の滑らかな減速**
   - 従来は少しでも超過すると移動40%、2.0kg超過で20%と極端だった。
   - V4では基礎重量上限を超えた **0.1kgごとに速度係数を0.006減算**し、最低60%で止める。
   - 例：0kg超過100%、+0.1kg約99%、+1.0kg94%、+2.0kg88%、+3.0kg82%、+約6.7kg以上60%。
   - 探索HUDの移動速度％表示は実際に使用する移動係数から計算する。警告の軽度/重度の分類は従来どおり。
   - V1〜V3は従来の40%/20%の段階制を維持する。

2. **遮蔽物で敵の近接攻撃を回避**
   - 予兆開始時の照準固定・距離・攻撃扇形・無敵時間判定はそのまま。
   - V4の攻撃確定時、敵とプレイヤーの間に壁や棚が入って視線が遮られていれば攻撃を受けない。
   - V1〜V3の被弾判定は変更しない。

3. **AUTOと手動の役割分担**
   - V4のAUTO攻撃だけ攻撃間隔を1.25倍にする（単位時間の攻撃回数は約20%減）。
   - 手動攻撃、命中判定、武器ダメージ・効果、武器切替によるクールダウン維持は従来どおり。
   - AUTOは探索中の利便性、手動は難所での火力効率という役割に分ける。
