# R4.5 — 横1行の財宝投入表・ルーレット長回転・手動停止スロット

更新日：2026-10-23

## 今回の変更

### 1. 財宝大勝負の投入一覧（Excel風）
- 以前の「スマホ2列カード」から、各種類・品質・複製区分ごとに横1行の表形式へ変更。行内で「小画像＋アイテム名／所持数／投入数／操作ボタン」を表示。
- 操作は `−` `＋` `全部` `1個残し`。「1個残し」は**その行で所持する対象のうち1個を残し、残りをすべて選択**する。所持1個なら投入0個。
- 既存のN全部、C全部、N/C全部、解除、レア度別フィルタ、並べ替えは維持。
- 小画面で列が収まらない場合のみ横スクロール。行の縦方向の折り返しは避けた。
- 保護品とお気に入りは従来通り投入候補から除外。賭けて消費したアイテムは図鑑の記録だけ残す。

### 2. ルーレット演出
- 3回転強・約1.5秒 → **8回転以上・約3.4秒**のCSSアニメーションへ変更。
- 当選結果は従来通り開始時の重み付き抽選で決定。停止したマスと表示結果は一致し、次回も停止角度から回り始める。
- 結果表示と再投入は約3.6秒後。回転中の二重投入を拒否。
- 既存の倍率・確率は変更していない。

### 3. スロットを「自分で止める」方式に
- 開始時にゲーム内Gを1回だけ消費し、3リールの絵柄を独立かつ等確率で抽選。結果はゲーム内の保存領域に確定し、各リールの`停止1`、`停止2`、`停止3`を**好きな順番で**押せる。
- 押したリールだけ停止表示になり、残りのリールはCSSで動き続ける。
- 3つすべて停止した時点で配当を1回だけ確定。ハズレや配当表はR4.4から変更なし。
- **停止タイミングによって確率・配当は変わらない。** 手動停止は緊張感と演出のための機能。
- 未終了の抽選は `state.arcadeSlotPending = {rolls:[0..4]×3, stopped:[boolean]×3, bet:'100'など}` で保存。終了時は `null`。ブラウザの再起動・ページ移動後も中断前から復元される。
- 途中で再度スロットを回したり、遊技場で別モードへ切り替えたりする操作を拒否。報酬二重受け取りを防止。
- 旧セーブは新フィールドを追加するだけで移行し、従来の `v:1`、IndexedDB v2、図鑑、資産、ガチャ進捗を保持。JSONインポートでは不正な途中記録を拒否。

## 実装ファイル
- `arcade.js`: 手動停止と保存、投入表の生成、1個残し、ルーレット長回転。
- `arcade.css`: 1行表・小サムネイル・回転し続けるリール・停止ボタン・長回転。
- `index.html`: `arcadeSlotPending` の初期化／正規化／インポート検証、JS/CSSのキャッシュバージョン。
