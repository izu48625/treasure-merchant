# R5.2.3b — 鑑定カードの線を減らす

更新日: 2026-10-24

## 目的
iPhone実機でR5.2.3aのカードを見た際、外周2本、画像窓の上下線、カテゴリ枠、品質／価値欄、極小フッターが重なって線の密度が高かった。今回は**色味やレア度の迫力を維持したまま線を削減する**。

## 実装
- `assets/cards/frame-{base,n,c,r,sr,ssr,ur,ex}.svg` を共通の外周矩形1本へ変更。SVGの内周線を削除し、線の太さを6pxから4pxへ。
- `treasure-card.css`: カード本体の擬似的な外周1pxリングを削除。SVG外周線を唯一の外周線にする。
- 画像窓は上線を削除し、下だけレア色の透明度28%相当の細い1px線にする。内部背景は単純な暗色を維持。
- カテゴリ2件は枠をなくし、薄い面色のみで表示。
- 品質／推定価値欄は上線を削除、中央の縦線は低コントラストに調整。
- 画面最下部の英文と番号の極小フッターをカード本体から削除。4領域（見出し16%、画像60%、カテゴリ8%、品質・価値16%）へ整理。
- `treasure-card.js` のフレームURLと `index.html` のスタイル・スクリプト参照をR5.2.3bに更新し、旧キャッシュを回避。
- 変更はガチャ・所持品・図鑑共通のカード部品に適用される。

## 不変項目
- 7レアの色・静的外周光・カード外形および画像データの読み込み方式
- ガチャ抽選・排出率・天井・セーブ・タスクキル復元
- 図鑑・所持品の検索・売却・保護・複製などの管理処理
- 結果の10連・50連、個別詳細表示

## 確認済み
- 7種類すべてで共通SVG座標 `340×476`、外周矩形1本、装飾パス0本。
- 全7レアのカードに画像1つ、品質、推定価値、レア表示が揃っている。
- CSSの括弧構造・共通JSとインラインJSの構文検証が通過。
- ガチャ・所持品・図鑑で共通の `treasureCard()` を参照している。

## 残る制約
- 実際のiPhone Safari画面での見た目・スクロール・保存操作の実機検証は未実施。
- 財宝の元画像は全20点が256px。高精細な再描画は未実施。CSSの修正では元画像のディテールは増えない。
