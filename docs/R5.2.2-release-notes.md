# R5.2.2 — 静的な財宝鑑定カードと画像品質監査

## 実装済み
- ガチャの個別結果を独立した「鑑定カード」へ変更。大型の財宝画像、レア度、名称、分類、品質、推定価値、鑑定番号を表示する。
- レア度N/C/R/SR/SSR/UR/EXそれぞれ独立の材質感と枠形状を採用。SSRは深紅＋赤銅の二重縁、URは黄金の厚い枠、EXは角を落とした黒紫＋白金の専用シルエット。
- 結果表示に新たなアニメーションは追加せず、静的な光彩と装飾だけで希少価値を示す。
- 単体結果では256px画像を約256 CSSピクセル以下で表示し、以前の1.48倍への無理な拡大を解除する。これだけでは本来の細部は増えない。
- 10連・50連の一覧はレアリティ別のカード枠を採用。各結果をタップすると同じ保存済みのアイテムを大型鑑定カードで表示。プレビュー操作はセーブに書き込まない。
- 結果用だけ実在する高解像度画像を優先し、一覧では軽量画像を使用する `TREASURE_DETAIL_ASSETS` マニフェストを追加。高解像度の取得失敗時は既存の画像へフォールバック。
- 20点の既存画像の解像度を調査し `docs/R5.2.2-image-audit.json` に記録。**全20点が256×256pxであり、現時点で新しい高精細元画像は未制作・未登録**。

## 今回変更していないもの
- ガチャ抽選・天井・初回特典・高級10連確定枠
- 保存済みの獲得品ID・品質と途中開封進捗
- アニメ付き宝箱の開封プロセス、即表示ON、10/50連、同条件再抽選、報酬付与

## 次の品質改善
既存の256pxをアップスケールするのではなく、実際に768〜1024pxで描き直した財宝原画を代表的なN/SSR/UR/EXから用意し、マニフェストへ登録する。現状の鑑定カードで迫力が出ても、元画像の真の解像度は変わっていない点に注意。
