# R4.7 — 160種類の相場パターンと6・12時間の確定予報

更新: 2026-10-24

## 要件
- 基本相場パターンを100種類以上（実装160種類）用意。
- パターンの法則を覚えるだけでは、次に何が起こるか予測しにくくする。
- **6時間後・12時間後のジャンル市場指数の予報は必ず合う**よう、未来の指数を事前に抽選・確定・保存する。
- ユーザーの売却数量を市場相場に反映させない方針を維持。
- 5ジャンルの性格（現代安定・歴史中変動・宝石高変動・骨董緩やか・神話稀な急変）を維持。

## 160パターンの仕組み
- 10種類の基本曲線：右肩上がり・右肩下がり・底打ち反発・天井反転・階段上昇・階段下落・急落反発・急騰から急落・レンジ乱高下・二番底から回復。
- 進み方4種類：等速・後半変動・前半変動・加速減速。
- 細かな揺れ4種類：なし・1周期・2周期・3周期を加えた変調。
- 合成で **10×4×4＝160通りの異なる基本形**。24時間・各ジャンルごとにランダム選択する。
- 選択後にもジャンル固有の変動倍率、1時間ごとのノイズ、稀な大変動、全ジャンル共通の小変動を加えるので、同じ基本形が選ばれても最終結果は同一にならない。
- 固定パターンを繰り返すのではなく、160基本形をベースに複数の乱数が組み合わされる構造。

## 未来確定と予報
- 新しい `marketV4` セーブに、過去の市場・未来の市場を時系列保存。
- 初回はR4.6の `marketV3` 履歴を取り込み、現在から約24時間先までの相場を抽選・保存する。
- 未来の残りが12時間以下になると、新たな24時間のパターンを追加する。すでに確定した時刻の価格は変更しない。
- 予報は `forecast(6)` と `forecast(12)` で、現在のジャンル指数と確定済みの未来の指数を比較した百分率を表示。「急騰・上昇・横ばい・下落・急落」に分類。相場表と市場グラフのカテゴリ指数は同じ `marketV4` の行を読む。
- **確定予報の対象はジャンル市場指数**。財宝個別価格・品質倍率・複製品補正・高騰イベントを組み合わせた最終売却額を保証する予報ではない。
- データは200〜256時間程度の範囲に抑える。長期間（例：4週間以上）の未起動から復帰するときは、古い未来の予約を再利用せず最近の架空履歴を生成することがある。

## 公平性と限界
- ブラウザ版はローカル保存なので **未来の値がセーブ内に存在する**。プログラムやセーブを解析できる人から未来を完全に隠すことはできない。
- 将来、実ユーザーのランキングや競争を導入する際は、サーバーが相場を確定・保存し、クライアントには確定予報と現在までの相場だけ渡す構成が必要。
- 乱数とパターンの選択には `marketRandom()`（`crypto.getRandomValues` を優先）を利用する。端末時計の改変やセーブ改変まで完全に防げるわけではない。
- 売却・アイテム消費では、市場指数・予報スケジュールを変更しない。

## 対応と互換性
- `index.html`: `MARKET_BASE_SHAPES`, `MARKET_PATTERN_BANK`, `marketShape`, `marketAppendPatternSegment`, `marketValidV4`, `marketAdvance`, `forecastHTML`、マーケット画面と3列の予報表CSS。
- 既存セーブのG、所持品、図鑑、ガチャ・売却回数を維持。R4.6市場の既存履歴は可能な限り引き継ぐ。セーブ形式 `v:1` と IndexedDB v2 の基礎構造は変更しない。
- 新市場データ `marketV4` は有効範囲・時間の連続性・価格レンジ・パターン番号を検証。JSON復元で無効データを拒否。

## QA
- 異なる160種類の曲線（24時間値25点の配列）を検証：**160種類すべて異なる**。
- 初回起動と再起動で将来確定値が変わらないことを確認。
- 表示した6時間後・12時間後の指数と、進めた時刻に表示する指数が完全一致。
- 12時間先がなくなる前に24時間分の予約を補充することを確認。
- 市場グラフで `NaN`／`Infinity`／`undefined` の表示がないことを検証。
- R4.6の古いセーブから移行、既存資産保持、図鑑保持、売却による相場不変、改ざんされた市場履歴のインポート拒否。
- **180日分の模擬市場**で160種類の全基本パターンが選ばれ、各ジャンルの変動性格と将来予報の整合を維持することを確認。
- 予報・ブラウザ再起動を含む35項目、旧セーブ・180日連続稼働21項目の模擬試験を通過。
