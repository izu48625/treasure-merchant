# 財宝探索 MVP（2026-10-25）
 
## 目的
既存の財宝アイテム（ITEMS／item.image）と宝箱アセットを使い、操作式の2D脱出モードを既存ゲームへ追加する。

## 遊び方
- 下部「探索」またはホームから移動する。
- 出発前に武器・探索道具・護符を所持品から選択する。
- スマホは左スティック、PCはWASD／矢印キーで移動。敵への攻撃は自動。
- 宝箱に近づき、開封操作で戦利品を入手。満杯ならバッグから破棄できる。
- 4分以内に緑色のEXITへ戻り、脱出ボタンで確定保存。死亡・時間切れ・離脱・再読み込みでは未確定の戦利品をすべて失う。装備品は失わない。
- 探索で獲得した財宝は既存の所持品・図鑑・市場へ反映。ガチャ抽選／スロット封印結果／既存の価格決定には触れない。
- ガチャ権利の追加報酬は試作版のため保管のみ。現行の「無料テストガチャ無制限」とは独立。

## 実装・保存境界
- exploration.js / exploration.css を独立追加。
- 既存の receive(it,q,replica,source) の source='explore' で図鑑の探索獲得数を分離。
- 旧セーブ互換を維持し、exploreEquip（装備品UID）を追加。売却済みUIDは無効扱い。
- 探索途中はメモリにのみ保持。帰還時に saveWithCommit の永続保存完了を待ってから成果を表示。
- 宝箱12、敵1系統（簡易円形）、マップ1、定数ベースのバランスは試作用。
- まだ課金・オンラインランキング・対人戦を統合しない。

## 確認記録

- モック環境の模擬プレイ：開始→自操作の移動→宝箱開封→帰還→獲得品受取の経路を通過。
- 未確認：実ブラウザの視覚検証、iPhone Safari実機、長時間耐久、IndexedDB障害中の回帰、バランス調整。
- 正式版前に 360/390/430px幅、iOSタッチ・誤タップ・画面中断・IndexedDBからの復元を実機確認すること。
