# R3.5 — 無制限テスト・現代ガチャ・品質管理・所持品集約

## 仕様と実装
- テストモード（TEST_FREE_GACHA=true）はチケット残高ゼロでも通常・現代・歴史・高級ガチャを引ける。ガチャを引いてもチケットと現金は消費しない。正式版に戻す場合はTEST_FREE_GACHA=falseとし、権利と価格のチェックを復帰させる。
- 権利の本番向け仕様: 30分に1枚補充、上限10枚。テストでは残高と回復は参考表示。
- 現代ガチャのプール: レアリティを基礎排出率で先に抽選、同レアに現代アイテムがあれば現代から抽選、なければ一般プールから抽選。レア保証は通常ガチャのみ。
- 品質確率: 低50%、中35%、高12%、最高3%。倍率: 0.7x / 1.0x / 1.6x / 2.8x。価格の品質以外の市場補正は従来どおり。
- 所持品: 同じ item.id + 品質 q + replica フラグで集約。保護状態はグループ内で個体ごとに保持。保護品は一括売却対象から除外。上限100件まで個体の詳細ボタンを表示し、残りはグループ一括操作に対応。
- 5列グリッド継続。グループカードに×所有数、保護数、グループ合算評価額を表示。
- 所持品のレアリティ・分類・品質・評価額・取得日ソート、レア/分類/品質フィルター、名前検索。図鑑の名前検索と発見品質順ソートも追加。複数選択は表示中フィルター変更後も保持。
- 旧 localStorage キー 'treasure-exchange-demo-r1'、v:1を変更せず、所持品個体レコード、図鑑、回数、歴史を引き継ぐ。集約は表示のみで個体を削除・圧縮しない。
