# R5.30 — 1階の内部構造を廊下・間仕切りで作り込む

## 目的
「開けたマップを一直線に走れば奥まで行けてしまう」問題に対し、面積や階層を増やさずに **既存1階の地形と視線・移動の駆け引き** を改善する。5分制限、固定脱出口、80物資（黄49/青27/紫4）、18か所の地域別巡回敵は継続。

## 実装
- R5.29までの14地帯に、**中央大型売場と東側売場を中心とした間仕切りとサービス廊下** を追加。
- 13種類の手設計ブループリント（防火区画・売場背面・サービス横断・倉庫/渡り廊下の境界・西側サービス区画）から、実家具・既存壁・出入口・旧脱出口候補と重ならない区間だけ実体化。
- 実際に追加された壁は **24片、合計延長4,220px**。18px厚の物理衝突壁であり、見かけだけでなく **敵の視線、プレイヤー移動、敵の経路検索** に効く。
- 140〜240px程度の通路・二重出入口をブループリントに設定。棚や木箱に近すぎる壁片は敷設せず、ユーザーが戦利品に近づける空間を残す。
- 追加壁の構造は既存の下見図と施設案内図にもそのまま反映（`walls`が描画・衝突・ナビの共通データ）。
- 敵の固定ポストは入口からの歩行可能領域で検証し、14地帯すべての計18地点を確保する。新壁で切り離された床に巡回敵を立たせない。
- 旧V4途中セーブのプレイヤー/敵座標が追加壁と重なった場合のみ、付近の **入口からつながる歩行可能位置** に補正する。既存の封印戦利品、敵HP、タイマー、出口IDを再抽選・初期化しない。
- V1〜V3旧マップ、ガチャ、市場、既存の戦利品・報酬結果を変更しない。新たな階層/ロード画面は作らない。

## 通過ルートと難易度に関する評価
- この段階では、一方通行の一本道や全ルート共通の強制戦闘ゲートを追加しない。敵から視線を切れる部屋や通路と、比較的広い売場の横断路を併存させる。
- **壁片の追加だけでは最短移動距離は大幅には増えていない**。R5.29までの最奥への最短往復69秒（無装備・交戦なし）から大幅に延ばしたとは主張しない。実際の難易度上昇は遮蔽物・視認・巡回の位置関係と実際のプレイによる。
- 次の調整候補：高級物資の奥へのアクセスに安全な遠回りと危険な短い通路を明確に区別する、扉／警備室／金庫室を設置する、巡回ルートを新しい通路に合わせる。ただし2階増設や敵数の倍増を先にしない。
