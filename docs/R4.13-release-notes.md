# R4.13 — 主要な情報をなるべく1画面に収めるUI改善

更新日：2026-10-24

## 目的
縦向きスマホで毎回見る情報と基本操作を画面上部にまとめる。画面幅が狭い端末でもボタンを極端に小さくせず、説明・高度なフィルター・履歴は任意で開く設計にする。
**ゲームのルール、ガチャ確率、賭け金、相場160パターン、確定6/12時間予報は変更しない。**

## ホーム
- 資産カードに「総資産・現金・財宝評価額」をまとめ、同じ現金と財宝の大きなカードを重複表示しない。
- 「所持数・図鑑進捗・累計ガチャ・ガチャ権利」を横4つのミニ指標に集約。
- 市場の高騰イベント有無、6時間後に最大の値動きがあるジャンルと確定予報をまとめて表示。
- 図鑑・称号へのショートカットをその下に残す。資産グラフと価値上位3件は折りたたみからいつでも閲覧可能。
- ナビのホーム／ガチャ／所持品／市場／遊技場はR4.11の5タブのまま維持。

## ガチャ
- 従来、通常・歴史・現代・高級の4カードを縦並びにしていた画面を、**4種類の切替タブ＋選択中のガチャ1件の操作カード**に変更。
- 通常・歴史・現代は「1回／10連／50連」を同時に表示。高級は既存の10連専用ルールを維持。
- 画面上部に現金とテスト/権利状態、結果即表示ON/OFFを置く。保証進捗50/100は選択中のボタン直下。
- 初回無料10連が未使用なら、メインボタン群の直下に表示。再度無料にならない既存ルールを維持。
- ガチャ確率、権利の細部、回復・広告予定の説明は折りたたみ。「直近獲得品」も折りたたみ。図鑑へのリンクは画面下部。
- 選択したガチャ種はタブ内で保持し、抽選後・結果画面からの同じN連周回時もその種類を維持。
- 正式版のガチャ料金・権利の可否判定は、操作ボタンごとにその回数の費用で制御。現在はR4.12からの無料テストモード。
- 画面内主要ボタンは44px以上を維持。

## 市場
- 5分類の**現在指数＋確定6時間後の騰落率＋確定12時間後の騰落率**を1つの5行表に統合。
- 高騰イベント開催中の情報は表の直下に簡潔に表示。グラフ（48時間/7日間と数値スライダー）は引き続き表の下に配置。
- 予報の詳しい基準、ローカル版で未来データを解析され得る点は折りたたみに移動。
- 以前と同じ確定済み `marketV4` を参照し、未来相場の予測値や価格には変更なし。

## 所持品
- 「現金／財宝」を横2つの小型欄にまとめ、重複した長い売却説明を省略。
- 名前検索・重複選択・高騰中選択・選択解除を上部に配置。
- 並び替えとレアリティ・分類・品質の高度なフィルターは「⚙️ 並び替え・絞り込み」で開閉。開いた状態は同じセッション内の再描画をまたいで維持。
- 画面下部の固定の選択・一括売却バーは従来どおり残し、売却時の確認も省略しない。
- 図鑑のショートカットも所持品パネル右側に残した。

## 遊技場
- 「遊技場＋残高」の見出しを1行にし、4つのモードを横1列に。
- 結果は従来の大きな別パネルと重複するスロットリール表示から、**直前結果を簡潔に表示し、内訳は展開式**に変更。
- ルーレット盤を通常画面で約150px（短い画面では約141px）に縮小。スロットのリールもわずかに縮小。
- 100G・1千G・1万G・10万G・100万Gの5つをコンパクトな横1列ボタンに。数値の意味が誤解されないよう `aria-label` に正確な金額を保持。
- 「もう一度回す」「演出を省略」「残りをまとめて停止」はR4.12と同じ動作・抽選条件で使用可能。確率表は従来どおり折りたたみ。
- 高さ740px以下の短いスマホ向け余白調整で情報を優先。ただし画面内に必ず全部収まる保証はなく、実機評価が必要。

## テスト
- 4つの実際のJSファイル（index内のメインJS、arcade.js、rich-ranking.js）を統合して構文を確認。
- 初回起動、5画面の内容・順序、ガチャ4分類、通常10連・結果画面から再抽選、所持品フィルターの開閉と固定売却バー、相場5ジャンル×現在/6h/12h、ルーレットの開始・スキップ・結果保持、スロットの一括停止など**49チェックをPASS**。
- 旧v1セーブから読み込んだ残高・ガチャ履歴・売却回数・追加権利の保持、保存→再起動、確定6h/12h相場の復元と6h後の実現など**17チェックをPASS**。
- 合計**66個の自動検証チェックを通過**（実機操作検証ではない）。
- 実際のiPhone SafariやGitHub Pages配信確認、ピクセル寸法・画面スクリーンショット・折返し・色覚・キーボード、複数タブのIndexedDB競合はまだ未確認。特に「1画面」はスクロールを**減らす**方針であり、端末・文字サイズごとに必ず無スクロールを保証するものではない。
