# R5.27 — 各区域の初期敵配置（地域別巡回ポスト）

## 背景
R5.26までの敵は出撃時にプレイヤー周辺へ2体、以後は時間間隔とプレイヤー周辺のランダム出現に依存していた。出撃直後に奥のエリアまで走ると、敵が誰もいない場所ができていた。

## 実装（V4施設のみ）
- authored V4の**全14区域**に固定巡回ポストを設置。中央大型売場・東側大型売場・北物流棟・北側資材倉庫は2地点、その他10区域は各1地点で**計18ポスト**。
- ポストの位置は床上で再現可能、壁・棚・搬出口・入場地点に重ならない。安全確保：入口から215px以上、既存出口から130px以上、同一ポスト間240px以上、敵半径を収められる空き床を確保。
- 地域に合った敵を配置：南搬入口や事務棟は通常、東側/整備棟/通路などは高速、隔離保管区・北物流棟の一角は重装。
- 出撃時に18地点を予約して、プレイヤーから490px以内、または同じ区域の650px以内に近づくと実体化する。目の前への突然出現を避けるため170px未満の地点では新規実体化しない。**探索開始時に遠くの18体を全てAI更新しない（iPhone負荷対策）**。
- 最初に南搬入口の巡回ポストが活動を開始。その上で従来の通常敵2体が周辺へ配置される。遠くのポストはその区域へ最初に接近した時点で、時間経過による追加出現を待たずに活動開始する。
- 同時活動数はR5.25の上限4〜11体を超えない。新しい区域のポストが上限のため活動できないときは、プレイヤーから720px以上離れた未交戦の巡回・探索敵のみを置き換える。追跡、攻撃、警戒中の敵は置き換えない。
- 活動済みポストは予約から削除され、倒しても同じ場所に再湧きしない。時間経過のランダム敵追加はこれまでどおり継続。
- 残りのポストIDを探索チェックポイントに保存して復元。重複・未知のIDは拒否。以前のV4チェックポイントには新たに予約ポストを割り当てて移行する。
- V1〜V3、既存の敵ステータスとレーダー、当選、装備、戦利品を変更しない。

## 別マップ構想（今回の実装対象外）
画像のような狭い可視範囲と懐中電灯の扇形は、今の施設を一律に暗くするのではなく、**停電した倉庫／夜間の施設**など固有の危険性を持つ別マップ向けのアイデアとして記録する。
- 基本は暗所、プレイヤーの近距離・ライトの照射範囲だけが鮮明。
- 敵にも照明やセンサーを持たせ、照明の形状と見つかる危険を表裏一体にする。
- 暗さにより操作対象・出口・敵の攻撃予兆が読めなくならないようUIや最低輝度を設計する。
- 現V4の画面全体を暗くする変更、ライト/暗所メカニクス、別マップの追加は**未実装**。
