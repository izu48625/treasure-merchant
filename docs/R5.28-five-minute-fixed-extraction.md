# R5.28 — 5分制限・固定脱出口・高レア区域の帰還リスク設計

## 目的
プレイヤーの「5分の探索制限／タルコフライクに固定脱出口／高レア物資のある区域からの帰還を難しくしたい」という要望を受け、新規V4施設を時間制限付きのルート選択型探索へ移行する。

## 今回実装：既存の一体型施設V4のみ
- **探索時間は300秒（05:00）**。開始時刻から計測し、0秒で通常の失敗清算（持ち込み装備と非保護戦利品ロスト）。脱出口での決済でも、期限超過時に逃げ切れないよう確認する。
- UIの探索時計は残り時間を表示。地図やバッグ操作で探索が一時停止中は残り時間も凍結し、再開時に進む。
- 新規V4出撃の脱出口は**西サービス棟の gate-08、座標(400,1550)** に固定。入口(340,2270)とは別地点で直線距離約722px。新規出撃では`pickExit()`が常にこの地点を返す。地図の大まかな出口区域は従来どおり見られ、施設案内図があれば正確な位置が分かる。
- 施設の18件の従来出口候補は削除せず`exitById`で維持。既存の旧V4チェックポイントが抽選した他の出口に帰還できるようにし、その画面では「固定」と誤表示しない。
- 旧V4の「無制限」途中セーブから初めて復帰するときは、**最低120秒の帰還猶予**を与える。新形式は`timeLimitVersion:1`で保存し、以後のロードで猶予を繰り返し獲得できないようにする。
- V1/V2の旧240秒タイマーと、V3旧迷宮の無制限・抽選脱出口は維持。ガチャ、レアリティ抽選方式、セーブ決済の不可逆性、マップ構造、敵HP/AIを変更しない。

## 高レア区域・帰還リスク：次の提案（今回未実装）
- **手前（南搬入口・西サービス棟）**：ありふれた物資、巡回敵は少なめ、出口に近く安全帰還が容易。
- **中間（中央大型売場・旧管理棟）**：中程度の貴重品、通常と高速型の巡回敵、探索時間とのバランス。
- **奥（北側資材倉庫・北物流棟・隔離保管区）**：金庫・高級物資／希少装備を出しやすくする。その代わりに奥地の重装敵、長い帰還導線、拾った荷物の重量で難易度を高める。
- 報酬と危険をセットで設計するのが重要。**現実装はまだ区域別の高レア排出優遇がない**（コンテナの種類に依存）。高レア区域の報酬率調整は実機で5分制限と固定出口の感触を確かめてから別の変更として行う。
- 入口/脱出直前に敵を無理に増やさない。帰還の難しさは、時間配分・重量・迂回／戦闘・強敵を避けるか倒すかという選択から生まれるようにする。
