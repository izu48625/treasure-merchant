# R5.2.3d — レア文字・枠色の不一致修正

更新日：2026-10-24

## 原因
ユーザーのiPhone実機画像ではヘッダーが **R5.2.3b** のままであり、R＝青文字／黄緑フレーム、N＝灰文字／茶フレームなど旧レア色の不一致が見られた。
R5.2.3cでCSS変数による統一を追加したが、一部はまだCSSの読み込み順・古いスタイルに依存する構造だった。

## 修正
- **`index.html`**: `badge(r)` で `RARITY_COLOR[r]` を直接レア文字とバッジのCSS変数へ指定。所持品・図鑑の `tile()` と `groupTile()` でもアイテムの実レア色をカードのCSS変数に直接指定。
- **`treasure-card.js`**: 共通の大きな鑑定カードのレア文字とカード自体に同じ `RARITY_COLOR` の値を渡す。7レアSVGは本来同じカラーを使う。フレームのキャッシュ参照をR5.2.3dに更新。
- **`gacha-ui.js`**: 10連・50連結果の各小カード枠に同じレア色を直接設定。表示のみの変更で抽選機能に影響しない。
- **`rarity-palette.css`**: 選択中の所持品カードが一律金枠になる表示を解消。レアの枠色を維持する。
- **キャッシュ更新**: `index.html` の版表記とカード・ガチャ結果・共通レア色CSSのキャッシュURLをR5.2.3dへ変更。

## 一致検証
| レア度 | 統一色 |
|---|---|
| N | `#a37651` 茶 |
| C | `#909aa4` 灰 |
| R | `#a4d64d` 黄緑 |
| SR | `#67d6b8` ミント |
| SSR | `#ee635d` 赤 |
| UR | `#f0c747` 黄金 |
| EX | `#a981f7` 紫、金ハイライト `#f0c95a` |

7種類について、JS関数生成のバッジと大型カード文字、CSS変数、SVGの単一フレームの主色の一致を確認。
`index.html`、`gacha-ui.js`、`treasure-card.js` のJS構文を検証。

## 未変更
- ガチャの排出率、天井、保存、売却、保護、図鑑データ
- カード形状・レア発光演出の基本方針
- 元の財宝画像（256px）

## 注意
ユーザー提供の画面は旧 **R5.2.3b**。古い表示を開いたままでは修正が反映されないので、必ずR5.2.3dの新しいURLを開き、上部のバージョン表記を確認すること。iPhone Safari実機での表示確認はユーザー側が必要。
