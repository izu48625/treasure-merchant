# R4.11 — 操作感重視のモバイルUI・ボタン配置

更新日：2026-10-24

## 目的
R4.8までのプレイ要素とゲームバランスを維持し、iPhoneなどの縦画面で片手操作しやすいUIにする。今回はデザインの全面リニューアルではなく、頻繁な操作の導線とタップしやすさを優先する。

## 変更したUI

### 1. 画面下に使う頻度の高い5画面を常設
- **ホーム／ガチャ／所持品／市場／遊技場** の5項目に集約。旧UIは6項目を5列のグリッドに置いていたため、意図しない折返し・圧縮のリスクがあった。
- 下部メニューの各ボタンは約58px以上の高さとし、絵文字とラベルを中央に配置。選択中の背景と枠を強調。
- 画面下端の `safe-area-inset-bottom` を考慮。現在の画面ボタンに `aria-current="page"`、絵文字に `aria-hidden`。
- **図鑑と称号は削除していない**。ホームの大きな2つのショートカットから直接開ける。ガチャ画面と所持品画面にも図鑑へのボタンを配置。
- 設定／説明は従来どおり上部のボタンから開ける。

### 2. 所持品の選択・売却を指の届く下端へ
- 所持品を1点以上選択したときだけ、下部メニューのすぐ上に**選択数／売却見込／解除／まとめて売却**の固定バーを表示。
- 選択解除・売却後、選択点数が0になればバーを自動的に隠す。
- もとの売却確認（現金・所持品額・総資産の変動と確認ダイアログ）を継続し、確認なしの即売却にはしない。
- 固定バーはモーダルより手前に出さず、保存画面やガチャ画面では表示しない。
- 財宝カード右上の「＋」を約32×32pxに拡大し、さらに見えないタップ領域を増やした。誤選択を減らすため、保護マークの位置も調整。
- 固定バーに隠れた最終行がスクロールで見えるよう下端スペースを追加。

### 3. 頻出ボタンの押しやすさとフィードバック
- 画面上の主要なボタンはおおむね46px以上。ガチャの操作ボタンは50px、遊技場のモード選択は50px、ベット選択46px、スロット停止48px。
- 遊技場の1行ステーク表は従来形式を保つ。極端な横幅を使うため4つの数量操作は横幅を無理に増やさず、縦の押しやすさを39pxへ改善。狭い端末では従来どおり横スクロール可能。
- 押下中の縮小・明るさ変化、キーボード操作でのフォーカス枠を追加。
- iPhoneのセーフエリア、上部ツールボタン、長い開発バージョン名のはみ出しも対策。
- 本版はタッチ操作を想定したCSS改善。実機での親指の到達性はまだ確認できていない。

## 維持した仕様
- 財宝取得・ガチャ確率、図鑑、売却価値、160市場パターン、6h/12h確定予報、称号、ルーレット・スロット・財宝勝負の動作。
- 所持品の選択保持と複数件確認ダイアログ。
- セーブ形式や既存のインベントリデータは変更しない。

## 検証
実際のJavaScriptをモックDOMで起動した回帰テスト**30項目**を通過：
- 下部ナビが5項目のみで正しい並び、アクティブ表示、遊技場への直接遷移。
- ホームから図鑑／称号へ、ガチャから図鑑へ、所持品から図鑑へ移動。
- 0点選択時は固定売却バーなし。1点・2点の選択数を反映、固定解除でバーが消える。
- 2点まとめ売却では確認1回、売却後の所持数0、G増額と固定バー消去。
- 市場履歴V4の検証、遊技場CSSのサイズ、キャッシュバージョン更新。
- 市場・ガチャ・遊技場の内部ルールに差分なし。

## 次の実機確認
- iPhone Safari 320〜430px相当の表示、親指の到達性、下部セーフエリア、横方向の余分なスクロール。
- キーボードを出した状態での選択バーと画面下ナビの重なり。
- 大量所持品のスクロール、iPhoneスクリーンリーダー、モーダルと固定売却バーの表示順。
- 現状のロードマップではセーブ・復元と多タブ競合対策（R4.10）がまだ残っている。R4.11はUI改善の先行実装として先に進めた。
