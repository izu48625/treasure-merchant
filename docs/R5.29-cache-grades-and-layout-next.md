# R5.29 — 物資3色・高級物資の遠方配置・次の地形改修判断

## 今回実装（V4のみ）
ユーザー要望「一般物資の黄色は残し、中レアと高レアで色を変える。黄色にもレアの抽選余地を残す」。

| マーカー | 意味 | 対象/件数（80物資/新規探索） | 色・形 |
|---|---|---|---|
| 一般（standard） | 普通の物資。まれに上位レア | 棚・資材箱・作業台 49個 | 黄色・小四角 |
| 中級（mid） | 上位品の期待度が中程度 | ロッカー・木箱25個＋西寄りの鉄箱/金庫2個、計27個 | 青・縁取り四角 |
| 高級（high） | 上位品の期待度が高い | 入口と出口から離れた鉄箱/金庫4個 | 紫・二重強調のひし形 |

- 色は **期待値** であり、開封前の確定中身を見せない。高級物資が常にレア品になるわけではない。
- 宝箱・金庫などからのアイテム抽選は出撃開始時に行い、探索開始チェックポイントに封印する。色による中身の再抽選は禁止。
- 新規V4のみ、標準物資のUR抽選確率をゼロにはしない（棚のUR約0.1%／1個の抽選。SR/SSRも従来どおり抽選）。上位レアが標準物資から出るサプライズを維持。
- 中級の西寄り鉄箱・金庫は通常の鉄箱/金庫の上位重みを下げ、近場に最高効率の物資が密集しないよう調整。
- 高級鉄箱なら SSR/UR/EX 合計約11.5%、高級金庫なら約18.5%（コンテナ内の1アイテムの抽選ごと。実際のアイテムプール存在に依存）。
- 高級物資は西側固定脱出口 gate-08 から **1700px以上** 離れた候補地点を優先的に選択する。現施設の既存棚・金庫・障害物は移設せず、既存の候補群から選択している。
- V1〜V3探索のレア抽選、ガチャ/市場、装備・死亡時ロスト、敵AI、マップ寸法・壁は変更しない。
- 以前のV4探索チェックポイントは **中身を一切変更せず** 色のみ新規分類で表示（既存アイテムが現在の色期待度と一致するとは限らない）。

## 現行マップの難易度監査
ユーザー体感：「まっすぐ進めば最奥に簡単に到着」。
V4の実地形 walkCells 上で、プレイヤーの無装備118px/sとグリッド最短歩行路を用いて概算：
- 出入口(340,2270) → 隔離保管区の固定巡回地点(3100,520)：4480px／約38秒
- 隔離保管区 → 西脱出口(400,1550)：3680px／約31秒
- 最奥まで行って戻るのに **最短約69秒（交戦・探索・回避・重量を除く）**。5分という時間制限だけでは、深部への到達を十分難しくできない。

## 次の開発優先度（未実装）
1. **廊下・間仕切り・フロア分割**：中央大売場の開放区画を、通路/棚列/管理室/防火扉/開いた搬送口で構成。最短直線を避け、少なくとも二本の実用ルート（短いが危険 / 長いが安全）を残す。戦闘中に視野を切る隠密性と、巡回敵に遭遇する要所の両方を作る。
2. **高級エリアへの危険導線**：東大型売場/北物流棟/隔離保管区に上級品を再配置し、帰還前に門・守衛区画を通るようにする。ただし通行不能・固定敵による詰みは避ける。
3. **敵配置や巡回の局所調整**：開放通路だけ単純に敵数を倍増しない。狭い通路で敵をかわす選択と、複数ルートからの追走を作る。今の追走速度・索敵角・数の上限は据え置きで開始。
4. **計測してから5分タイマー調整**：無装備・低装備・高装備で往復に要する時間、平均戦闘数、到達/脱出率、iPhone SafariのFPSを測る。ルートと物資分布調整後に時間の過不足を再判断。
5. **二階・新マップ/暗所は後工程**：二階は垂直移動・階段・別階地図・上下索敵等の実装工数が高く、現マップの直線走破の根本対策にはならない。次の別マップの個性として検討。

今回は「物資色と抽選期待度の可視化」まで実装。大規模な地形変更（衝突・巡回経路・脱出口の移動可能性・チェックポイント座標の互換を破壊しやすい）は、上記のテスト計画と併せて別変更として進める。
