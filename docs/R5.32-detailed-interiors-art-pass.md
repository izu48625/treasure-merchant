# R5.32 — 参考画像に基づく屋内グラフィック密度改善

## 目的
ユーザーの参考画像（荒廃した薬局の室内、工業施設の屋外）を参考に、R5.31 Tiled試作の優先課題である**床・壁・家具の情報密度と部屋の識別性**を引き上げる。既存本編R5.30マップは残す。参考作品の画像・ゲーム素材をコピーせず、ドット絵は新規制作する。

## 実装完了（試作屋内マップのみ）
- Tiled外部タイルセット `warehouse.png` を128×64px・32タイルから **128×192px・96タイル** に拡張。元の1〜32番タイルの見た目・IDを保持。新規64タイルを描画。
- 追加タイル構成
  - 33〜40：欠けた病院タイル・工業床・錆びた床・グレーチングなどの**歩行可能な床**。
  - 41〜64：血痕・油染み・ヒビ・ガラス片・紙くず・足跡・配線・汚れなどの**透明な環境デカール**。
  - 65〜92：薬棚、冷蔵庫、キャビネット、警備端末、金庫、保管棚、機械、ラック、机など**28種の衝突家具**。
  - 93〜96：破片や雑品の**非衝突オブジェクト**。
- 元の`Floor`・`Scars`・`Walls`・`Furniture`レイヤーを残し、`Patina`（汚れ）と`SetDressing`（追加家具）を挿入。
  - 596マスの床を区画用途に合わせて再選択。
  - 221マスの透明汚れ・破片、68か所の衝突家具、30か所の非衝突小物を追加。
  - 薬局は明るめ医療タイル／薬棚、警備室は暗い鋼色／端末、資材倉庫は格子床・パレット・物資棚、金庫区画は重金属床・大型金庫・警告灯など、部屋ごとに色と用途を変更。
- `Atmosphere`というTiledオブジェクトレイヤーに**11灯の小さな照明**と**6か所の部屋看板**を追加。
  - 属性`color`・`radius`・`caption`はTiled上で編集可。
  - ブラウザの`tiled-runtime.js`は画面内のみ照明グラデーションと看板を描画、マップ全体図では暗さの描画を抑制。
- 新家具の`solid`属性を読み取り、プレイヤーの移動と敵の視線を同じ衝突情報で判定するよう修正。
- 本編のガチャ/市場/課金/報酬/保存は変更なし。**新マップは引き続き独立した試遊ページ**。既存のR5.30探索も利用可能。

## 安全性と検証
- 新しい家具を置いた後も、入口・脱出口・物資11か所・敵6体・ゲートに衝突・通行不能なし。
- 入口から歩ける床は新規配置前1,271セル → 新規配置後1,201セル。家具増加に見合った減少で、既存の目的地には接続を維持。
- V8模擬CJS試験：**屋内13件 + 既存探索132件 = 145/145** 成功（2026-10-28）。
- PNGの取得・画像としてのデコードを確認。旧32タイルを残し新64タイルを描画した96種アトラス。
- 正式なNode CLI、TiledアプリでのGUI表示、GitHub Pages配信後のブラウザE2E、iPhone Safari実機の見た目・FPS・操作感は**未検証**。形式の互換性について実機やTiled実行での検証完了とは表現しない。
