# R4.2 — コレクション図鑑と収集記録

更新日: 2026-10-23

## 方針
- 主役は財宝を集める行為。R4.1の商人リーグ／品評会のルールは変更しない。
- 財宝を一度でも獲得すれば図鑑に永久登録。売却して所持0でも発見済みを維持する。
- 将来のアイテム別・ジャンル別オンラインランキングを見据え、現所持数／累計入手数／獲得経路を区別する。

## 実装した画面
1. 図鑑トップに全体の発見率、現在所持中の種類数、最高品質の発見種類数を表示。
2. 5つのジャンル別・7つのレアリティ別、4つの品質別の発見進捗を表示。
3. 図鑑を「すべて・発見済み・未発見・現在所持中・お気に入り」で絞り込める。
4. 所持数順・最新の獲得順で並び替えられる。
5. 発見済みタイルに現在所持数／累計獲得数、お気に入りの印を表示。
6. 詳細画面に発見記録とお気に入りボタンを追加（100種類まで）。

## データ・セーブ
- 変更先: `index.html`（静的JSとCSS）。
- `state.favorites: string[]` に発見済み財宝IDを保存。
- 各 `state.disc[id]` に `legacyQty`, `gachaQty`, `replicaQty`, `firstObt`, `lastObt`, `qualityMask`, `qualityHistoryPartial` を追加。
- `qty` は従来どおり**全入手数（複製を含む）**。新しいガチャ入手と複製入手は分離計上。
- `qualityMask` は4ビットで、取得を確認した品質を表す。新規に取得した品質のビットだけ追加し、売却後も残す。
- 旧セーブの `qty` を `legacyQty` へ移し、過去のガチャ／複製内訳は推定しない。既存の `best` に対応する品質だけを発見確認済みとし、他の過去品質は不明と表示。
- 旧セーブの初回・最終入手日時は推定しない。R4.2導入後の入手から最終入手日時を記録。R4.2以降に新規発見したアイテムは初回も記録。
- インポート検証にお気に入りID、品質ビットマスク、各収集件数の妥当性・内訳合計の確認を追加。
- 既存の保存キー `treasure-exchange-demo-r1`、データ `v:1`、IndexedDB v2、増分保存、JSONエクスポート／復元は継続。
