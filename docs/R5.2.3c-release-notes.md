# R5.2.3c — レアリティ配色と発光の統一

2026-10-24

## 変更内容
- 7レアの色を **EX 紫＋金／UR 黄・黄金／SSR 赤／SR ミント／R 黄緑／C 灰／N 茶**に確定。
- `rarity-palette.css` に CSSカスタムプロパティの共通パレットを導入。従来の `index.html`、`visual-polish.css`、`gacha-ui.css` に存在する旧レア色による競合を、最終読み込みの共通パレットで解消。
- `index.html` の `RARITY_COLOR` と旧 `.r-N` から `.r-EX` の色を新パレットに合わせた。全画面の色定義を同じ値に調整。
- SVGフレーム8種類を共通の340×476・**外周1本だけ**の形状のまま更新。EXは紫色の金属枠に金色ハイライトを溶かした1本のグラデーション。URは明るい金のグラデーション。
- EXとURの大型カードは静的な外周の光彩を強め、スマホのスクロール枠で外側の影が切れても見えるようカード内にもわずかに光彩を付加。
- ガチャ結果の小カード・バッジ、所持品・図鑑のタイル外周も同じレア色に。旧CSSの二重線・別のレア色を上書きするが、R5.2.3bの整理したカード構造は維持。
- `treasure-card.js` と `index.html` の参照バージョンを R5.2.3cへ更新し、旧デザインのキャッシュを回避。
