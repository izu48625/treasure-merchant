# R5.25 — 長めの追跡と遭遇頻度アップ（V4のみ）

## 実機フィードバック
「敵がこちらを見つけたらもっと追走してほしい」「もう少し敵に当たりたい」「数を増やすかレーダーを増やすか。時間経過で増えるなら良いのか」。

R5.24まで、敵は定期出現していたが、同時敵数上限は **探索の深さと戦利品の個数だけ** で決まり、時間だけでは増えなかった。初期の上限3体、レベル別3/5/7/9体、出現間隔19秒（深い場所15秒）。巡回地点から380px程度移動した通常敵は追跡をやめ、攻撃から回復した敵は追走中でも探索状態に戻っていた。また施設全体で遠方の敵が上限を占め、新たな遭遇が生まれにくかった。

## 変更（V4一体型施設のみ）

### 追跡
| 敵 | 発見後に姿を見失う距離 | 巡回地点からの追跡上限 |
|---|---:|---:|
| 通常 | 320 → 465px | 380 → 670px |
| 高速 | 350 → 510px | 435 → 800px |
| 重装 | 280 → 390px | 330 → 565px |

- 姿が見えなくなっても追走を続ける時間を **2.1秒→4.3秒** に拡大。
- 見失った位置での探索時間を最長約 **3.6秒** に拡大。到着した瞬間に諦めずその場で周囲を見回す。
- 攻撃後の回復が終わったとき、相手がまだ見えていれば即座に追跡へ戻る。旧仕様のように一旦探索へ戻って隙を作らない。
- 壁・棚による視線遮断と、距離や時間経過で追走が終了する条件を維持。逃げ切れない無限追跡にはしない。
- **未発見時のレーダー距離・視野角は変更しない**。敵の移動速度・HP・ダメージも据え置き。

### 敵の遭遇頻度
| 項目 | 従来 | R5.25 |
|---|---|---|
| 探索深度0/1/2/3の同時敵上限 | 3/5/7/9 | **4/6/8/10** |
| 時間経過補正 | なし | 90秒以降+1体、210秒以降+2体（最大11） |
| 初回追加出現 | 15秒 | **12秒** |
| 追加出現間隔（浅い区域） | 約19秒 | **16秒** |
| 追加出現間隔（深い区域） | 約15秒 | **14秒** |

- 瞬間にまとめて湧かせず、従来どおり出現タイミングにつき最大1体。
- 広い施設に居残り、上限だけ圧迫する **950pxより遠くにいる未交戦の巡回・探索状態の敵** は定期出現時にリサイクル可能。ただし視線が通っている敵、警戒・追走・攻撃・回復状態の敵を消さない。
- 新しい敵の出現可能な位置は従来どおりプレイヤーから210〜340pxほど離れた衝突のない場所とし、生成候補の試行回数だけ22→40に増加。新たな建物・報酬・抽選は追加しない。

## 互換性と検証
- `mapVersion: 4` 限定。旧マップV1〜V3のAI、敵数の上限、初回追加時刻、出現間隔を変更しない。
- 既存の探索チェックポイントの保存形式を変更せず、既存の探索の再開にも適用される。以前の`spawnAt`はチェックポイントから維持されるため、途中再開直後に新仕様の12秒が上書きされるわけではない。
- V8モックCJS系 **105件全合格**（2026-10-28）。Node CLI正式テスト、Safari/iPhone実機およびFPS/実遭遇率の実測は**未実施**。
- 実機では、1体に見つかってからの追走、棚越しで追い払えるか、90秒・210秒後の遭遇増、上限時の遠方敵リサイクル、敵の集まり過ぎによる連続被弾を確認する。
