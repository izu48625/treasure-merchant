# R5.14 — ランダム脱出口と地図アイテム（2026-10-28）

## 実装
- 廃商業区 R5.13 の3,600×2,600px/48区画マップを継続。
- 脱出口はスタート地点と別の区画へ。最短経路の深さ16以上にある**25候補区画**から、出撃ごとに一つ抽選する。入口と同じ位置にはならない。
- 出撃開始時の抽選結果は `exitId` として探索途中セーブに封印。探索中の再抽選や、再読込で出口が切り替わることはない。
- 既存R5.13チェックポイント（`exitId`が存在しないもの）は以前の出発地点と同じ出口を維持。R5.12/R5.11のマップは変更しない。
- 地図ボタンをゲーム中に直接表示。選択中は敵・戦闘・時間が停止。通常地図は**4列×3行の概略区域**と、現在地がある区域・脱出口がある区域を示すのみ。正確な出口座標や全通路は表示しない。
- 地図アイテム **施設案内図 (ITM-00901)** を追加。レア度C、価格850、重さ0.2kg。既存ガチャと新マップの探索品候補に追加し、探索道具枠に装備可能。仮のSVGイラスト。
- **案内図を探索道具枠に装備しているか、今回の探索バッグで拾って保持している場合**、全48区画の接続・現在地・入口・ランダム決定された正確な出口を表示。アイテムを外す／捨てると概略地図へ戻る。
- 地図アイテムの装備で攻撃・HP・移動速度への追加ボーナスは与えない。持込装備として死亡・途中撤退によるロスト対象。拾った地図も通常の戦利品管理に従う。
- 地図メニューは直に開けば閉じるとプレイ再開。一時停止メニュー経由では閉じると一時停止に戻る。
- 以前の4分タイマーは引き続き廃商業区R5.13/R5.14には適用しない。全体の制限時間仕様は保留。

## 実装ファイル
- `exploration-layout-v3.js`: `exitCandidates`, `pickExit`, `exitById`。
- `exploration-map-item.js`: 施設案内図の新アイテム定義。
- `index.html`: アイテムを `ITEMS` / `ITEM_BY_ID` に登録、R5.14のモジュール読み込み。
- `exploration.js`: 出口保存／復元／条件付きマップUI／拾得・装備による詳細地図判定。
- `exploration.css`: iPhone用地図ボタンと概要マップ表示。
- `tests/exploration-exits.test.cjs`: 9件の新しい回帰テスト。

## 検証と制限
- 既存3スイート27件＋新規9件、**計36件のV8モックによるコード実行テストが成功**。
- 25候補地点は全て入口から500px以上離れ、存在する区画の中に置く。
- 旧セーブ・途中再開・カタログ追加とR5.14スクリプト読み込み順を検証。
- **未実施**: iPhone Safariでの実機操作、公開GitHub PagesのブラウザE2E、ランダム位置25か所の全実地脱出プレイ、長時間ゲームプレイの難易度・UIの検証。
- Map UIはCanvasの室内視界とは別のSVGを使用し、詳細通路は線図で描く試作段階。高精細背景イラスト・案内図の正式アートは後工程。
- ランダムな脱出口は25候補から抽選するが、出口周囲の専用警備・開錠・一方向扉はまだ追加していない。
