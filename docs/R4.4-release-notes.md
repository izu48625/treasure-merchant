# R4.4 — 7点改修の実装記録

更新日: 2026-10-23

## 実装範囲
1. SR以上確定を累計50回ごとへ変更、SSR以上100回保証は維持。周期は `draws%50` に基づき、旧セーブでも保証の進捗を正しく再構成する。
2. 市場グラフは3時間おきのサンプリングへ変更。48時間表示＝16区間/17点、7日＝56区間/57点。短周期の正弦波ノイズを抑えた。相場の1時間更新・ガチャの基本金額は変えない。
3. 商人リーグはホームカード・ルート・報酬操作から隠し、昇格等の旧保存情報を保持する休止方式。
4. 長者ランキングを世界30人・日本30人へ拡充。元資料の固定推計を使用する。
5. ホームの長者番付カードを削除。称号画面に「称号・実績」「長者ランキング」の二段タブを追加。長者タブには世界／日本の切り替えを置く。
6. 財宝大勝負の投入候補を画像付きコンパクトカード化。スマホ2列、広い端末3列。N全部、C全部、N/C全部、解除の操作、レア度／並べ替えを追加。賭けた財宝は勝敗によらず消失する一方、永久図鑑記録は保持。
7. ルーレットは当選分布に合わせた円形ホイール、スロットは3本のリールを順次停止させる軽量CSS演出。抽選確定後に表示アニメーションを走らせ、演出中の二重操作を防止。reduced-motionに対応。

## 富豪データの基準・注意
- 世界：Forbes Australia, *The Forbes Billionaires List: Top 200*、2026年3月1日時点、上位30人／組。単位は10億米ドル。
  https://www.forbes.com.au/news/billionaires/the-forbes-billionaires-list-top-200/
- 日本：Forbes JAPAN *日本長者番付 2026*、2026年5月22日時点、上位30人／組。表示金額は日本円（億円）。
  https://forbesjapan.com/feat/japanrich/
- 固定の参考比較。リアルタイムの更新や順位変化は反映しない。
- 仮想ゲーム内計算で1G＝1USD、参考換算に1USD＝159円を仮定（実勢為替ではない）。
- 人名や資産額、出典リンクを非公認として紹介する。広告付き商用公開前に再利用条件等を確認すること。

## 変更ファイル
- `index.html`: ガチャ周期・市場グラフ・リーグ休止・称号タブ切替・遊技場フィルタ・アセット読み込み
- `rich-ranking.js`: 世界／日本TOP30の静的数値・ランキング表示
- `arcade.js`: 小型画像付き投入カード・一括投入・絞り込み・ルーレット／スロット演出
- `arcade.css`: スマホ2列/大画面3列、回転円盤・停止リール・reduced-motion
- `README.md` と本ドキュメント：更新記録
