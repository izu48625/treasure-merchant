# R4.5.1 — スロットの絵柄を停止した瞬間に確定

更新日：2026-10-23

## 変更理由
R4.5までは「回転を始めた時点で3リールの結果を抽選し、各停止ボタンは表示を公開するだけ」だった。ユーザーの要望に合わせ、**押したリールがその時初めて抽選される**方式に変更。

## 動作
1. 開始ボタン：選択した仮想Gを1回だけ支払う。3リールの結果はすべて未確定（`null`）。
2. リールの「停止」ボタン：押された1本について `arcadeRand(5)` を1回だけ呼ぶ。5絵柄は各20%。その絵柄を確定表示し、停止位置を保存。
3. 1本目／2本目：残りのリールは未確定のまま回り続ける。配当はまだ処理しない。
4. 3本目：最後の絵柄が確定した後に、3つの絵柄から当選区分と配当を計算する。報酬を1回だけ付与し、途中記録を `null` に戻す。
5. 停止後の同じボタン再押下や、未決着中の次回抽選は拒否する。

回転中の見た目は演出であり、ユーザーの反射神経や停止タイミングで特定の絵柄を狙うゲームではない。各リールは停止時に独立に20%で抽選されるため、従来の配当・確率（全部異なる48%、2個一致48%、3個一致4%）は変更なし。

## 永続データ・互換性
- 新しい途中記録：`arcadeSlotPending:{slotVersion:2,bet:"100",rolls:[null,null,null],stopped:[false,false,false]}`
- ボタンで確定したリールだけ `rolls[index]=0..4`, `stopped[index]=true` に更新。ブラウザの再起動・別画面からの復帰でも同じ未確定・確定状態を維持する。
- **R4.5途中セーブからの移行**：すでに停止したリールの絵柄と投入Gは維持。まだ停止していないリールの旧・事前決定値は破棄し、`null` に更新。二度目の投入はしない。
- JSONインポートでR4.5形式とR4.5.1形式を検証し、未停止のリールに確定済みの数値が入ったR4.5.1形式を拒否。
- `VERSION=1`、IndexedDB v2、図鑑・所持品・資金・ガチャ累計等は維持。

## QA

- 同じリールを二度止めても再抽選・再払戻しされないこと
- 3つ目を止めて初めて配当・結果が出ること
- 1本停止後に再起動し、未停止リールを残して復帰できること
- R4.5途中記録からの移行、JSONインポート検証
