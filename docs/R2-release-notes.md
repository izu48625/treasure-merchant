# R2: UI・売却会計・フィルターの改善

更新日: 2026-10-20

## 追加
- ガチャ開封モーダル、順番鑑定、高レア強調、スキップ、10連結果一覧
- アイテム詳細（品質・分類・時価・過去24時間の価格グラフ・6/12時間参考予報）
- 所持品: 入手順/価値順/レア順/5大分類順、レア/分類を個別に絞り込める
- 図鑑: 4種類の並べ替え、未発見シルエット
- HOMEと所持品: 現金/アイテム総額/総資産を分離表示
- 個別/複数売却: 確認ダイアログに売却前後の現金、アイテム評価額、総資産を表示

## 会計のルール
- `売却価格 = 現在の時価`
- `売却後現金 = 売却前現金 + 売却価格`
- `売却後の所持品評価額 = 売却前の評価額 - 売却価格`
- `総資産 = 現金 + 所持品評価額` なので、同一時点・手数料なしの売却では総資産は変わらない
- 売却した個体は所持品から削除するが、発見図鑑は消さない

## 互換性
- 元の `localStorage` キーとスキーマ `v:1` は維持。R1のセーブを初期化せず継続。
- 既存アイテムID/ガチャ確率/市場モデル/保存方式は変更なし。
