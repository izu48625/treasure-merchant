# R5.2.3e — 所持品カードのコンパクト化

2026-10-24

## 実機フィードバック
R5.2.3cのスクリーンショットで所持品一覧の縦長カードが大きく見えるとの指摘。横5列は維持し、一覧密度を高める。見た目の修正だけで抽選／セーブ／売却等のロジックを変えない。

## 修正
- 新規 `inventory-compact.css` をスタイル群の最後にロード。所持品の`.inventory-five`にのみ適用。
- 5列はそのまま、カード画像の表示領域を `clamp(48px,14vw,66px)` に制限。従来は画像の正方形表示（カード幅に比例）だった。スマホ幅によって削減率は異なる。
- 2行の名称欄を保持したまま、品質・価値の上下間隔を縮小。`+ / ✓`の見た目は27pxだが、実際のクリック領域はカード内44×44pxで確保。
- SSR/UR/EXの一覧カード周辺の光彩を控えめにし、カードが実際より大きく見える印象を抑える。
- **大型の鑑定カード、ガチャ10連50連結果、図鑑カードの大きさは変更しない。**
- `index.html`のタイトルおよび新規CSSのキャッシュバストをR5.2.3eへ更新。

## 静的検証
- CSSの構文括弧整合性
- 固定5列レイアウト
- `+ / ✓`の実操作領域44pxと装飾領域27pxの分離
- CSSの読み込み順（最終段に`inventory-compact.css`）
- インラインJSの構文検証
- R5.2.3dとの差分で `gacha()`, `inventory()`, `gallery()`, `saveWithCommit()`の元コードが文字列レベルで一致

## 留意事項
- 実際のカード高さは画像幅・財宝名・iPhoneフォントサイズで変化するため、一律の縮小率を実機測定したわけではない。
- 実機でのR5.2.3e表示・タップ精度は未検証。画面右上のバージョン表示がR5.2.3cなら旧キャッシュ／旧版。
