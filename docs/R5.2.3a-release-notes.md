# R5.2.3a — シンプルな鑑定カードへの修正

更新日：2026-10-24

## ユーザー実機レビューからの課題
- R5.2.3のSVGフレームが金属装飾・王冠・曲線・上下の水平線を持ち、文字や品質欄に重なっていた。
- 内部区画はCSSによるグリッドで別途管理しており、フレームSVG側の線と同期していなかった。
- 参考のWikiガチャに比べ、余計な装飾・英語ラベル・二重枠が多く、カード自体が騒がしかった。

## 実施した修正
1. `assets/cards/frame-base.svg` および `frame-n.svg`〜`frame-ex.svg` の8枚を完全に作り直した。全て **340×476の共通キャンバス**、角丸外周1本＋ごく細い内周1本のみ。SVG内の王冠、内部区切り線、角の模様、宝石、文字は廃止。各SVGは同じDOM構造、同じ形状で、金属色だけが異なる。
2. `treasure-card.js` において、レアリティ＋財宝名を一つの見出し領域に統合。英語の過剰な等級名をカード面から削除。カテゴリ・品質・推定価値・鑑定番号を維持。高精細画像がない場合の256px元画像処理は変更しない。
3. `treasure-card.css` を置換。単一のグリッド（見出し15％／画像58％／カテゴリ8％／価格等15％／フッター4％）で内部情報を管理する。外周SVGは外形だけを描き、文字と交差する要素を持たせない。
4. SSRは赤、URは黄金、EXは紫白金の外枠と静的光彩。すべてのレアで同じ形状を維持。アニメーションは追加しない。
5. 既存のガチャ・所持品・図鑑の共通描画経路 `treasureCard()` を維持。売却・保護・図鑑の発見状態・ガチャの抽選ロジックには変更しない。
6. `index.html` のスクリプト／CSSのバージョンを R5.2.3a に更新し、キャッシュされた旧フレームを回避するため `frame-*.svg?v=R5.2.3a` を参照。

## 実施済みの検証
- 新しいフレーム8枚は全て `viewBox="0 0 340 476"`、内部の `<path>` 0個、`<rect>` 2個と確認。
- 全レア7種で同一マークアップ、画像、レア度、財宝名、品質、価値、適切なフレーム参照を模擬生成。
- `index.html`、`treasure-card.js`、`gacha-ui.js` のJavaScript構文チェック通過。
- CSSの括弧数の整合を確認。

## 未実施・保留
- iPhone Safari実機での見た目／はみ出し／長い名称／操作ボタンとカードの重なりテストは未実施。
- 財宝の元画像20枚は依然 **256×256px**。真の高解像度画像は新規制作しておらず、画質の根本改善は次工程。
- 結果スキップ、タスクキル中断、売却／保護の実機試験は未実施。既存のゲームロジックを編集していないが、実機確認が必要。
