# R4.3 — 商会遊技場の試作

更新: 2026-10-23

## 追加機能
ホームの「🏦 商会遊技場」から4つのモードにアクセスする。6項目の下部ナビゲーションは据え置き。

### 財宝大勝負
- 目標を全アイテムから選択し、所持品（同ID・品質・複製区分）ごとの点数を指定して投入する。
- 初回50グループ表示、さらに表示可能。N/C一括選択と全解除ボタンを用意する。
- ロック中・お気に入りアイテムは賭けられない。
- 投入評価は `original = item.base`、複製は `floor(item.base × 0.45)` を各個体に適用する。品質・市場時価は評価に使用しない。
- `chanceBps = min(9000, floor(totalBaseValue × 9000 / target.base))`（1bps=0.01%）。0bpsの挑戦は拒否。
- 成功：投入品を消滅させ、選んだターゲットを1点獲得する（品質は既存のレア度別品質抽選）。
- 失敗：投入品だけ消滅する。成功時も失敗時も投入品を返却しない。
- `disc` の発見・品質・累計入手記録は維持。売却回数 `sells` は増加しない。
- 操作前に個数・基本金額合計・確率・不可逆消失を明記した確認を出す。
- 1万個の一括選択を模擬検証済み。25万個級の実機表示は未検証。

### 無料財宝チャレンジ
- 一日一度、費用0で狙った財宝を抽選。
- `chanceBps=min(3000, floor(1000 × 9000 / target.base))`。品質は既存の抽選。
- `arcadeFreeDay` をセーブに追加。旧セーブでは空文字から開始。
- 端末の `day()` に依存するため、テスト版では時計操作やテスト時間進行による不正対策はない。

### 商会ルーレット
- G投入額：100 / 1,000 / 10,000 / 100,000 / 1,000,000。
- 結果は合計10000分率から選択。ハズレ40%、1倍G27%、1.5倍G18%、2倍G9%、3倍G4%、ガチャ権利1.5%、財宝0.5%。
- まずGを差し引き、当選した配当を加算。配当倍率は元本込み。
- ガチャ権利：1,000Gあたり1回、最低1回、最高50回。現在はテスト版でガチャ権利を消費しない。
- 財宝：基本金額が投入額の5倍以下の候補から1点（できるだけ投入額20%以上の候補を優先）。該当なしは2倍Gへ代替。

### 商会スロット
- 3リール×5種類。各リールの各絵柄は20%で独立抽選。
- 全部異なる48%：0G。2個一致48%：投入額の1.25倍G。
- 3個一致4%（各絵柄0.8%）：🪙4倍G、🎟️ガチャ権利、🎁財宝、💎8倍G、👑15倍G。
- ガチャ権利：500Gごとに1回、最低1、最高50。財宝抽選はルーレットと同じ。
- 見た目は結果の3絵柄を表示。抽選済みの結果を後から変更する演出はない。

## 保存・互換性
- 新ファイル `arcade.js`, `arcade.css`。従来 `index.html` に読み込みとイベント委譲、ホーム導線を追加。
- データ項目 `arcadeFreeDay` を追加し、旧セーブを正規化。日付形式の不正なJSONを拒否。
- `v:1`、IndexedDB v2、既存20アイテム・相場・ガチャ確率・R4.1 NPCリーグ・R4.2図鑑の仕様を維持。
- 成功と消失は同じ操作内で `markDelete` と `receive` を使用、最後に `save()` 一回。
- 端末内プロトタイプのためランキングの正当性を保証しない。
