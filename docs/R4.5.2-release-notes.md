# R4.5.2 — 市場グラフの自然な値動きと長回転ルーレット

更新日：2026-10-23

## 依頼と修正概要
1. **市場グラフが滑らかすぎる問題**：従来は `sin` の合成を市場指数に用いていたため、48時間・7日間のチャートが大きな曲線になっていた。これを毎時間の不規則な指数変動へ変更し、3時間おきの値を折れ線で結ぶ表示にした。
2. **ルーレットをもっと長く**：8回転程度・約3.4秒だった回転を**22回転以上・約8.5秒**へ変更し、約8.8秒で結果を表示・再投入可能にする。

## 市場の実装詳細
- 共通市場ショックとジャンル個別ショック、稀な大きめの変動を擬似乱数で生成する。22/33回程度の価格反転を7日間で検出（基準テスト日の5ジャンルは22〜33回）。
- `categoryMult(group,h)` の価格指数自体を正弦波から更新。ガチャ後の売却価格 `price()` と市場グラフは同じ関数を参照するため、チャートと売買価格の数値に不整合を作らない。
- 1時間ごとの内部価格更新は維持。折れ線は3時間間隔でサンプリング：48時間=17点、7日間=57点。
- `seeded()` により**同じ時間・同じジャンルの指数は同じ値**となり、アプリの再読み込みで相場履歴が毎回入れ替わらない。
- ショックの影響は時間経過で減衰する平均回帰モデル。値域は従来通り700〜1400の倍率区間に制限、同時に1600件までキャッシュ。
- グラフ下の騰落率は `(期間末指数 / 期間初指数 - 1) × 100` を基準に表示。
- これは現実の為替や金融商品の価格を参照するものではない。「ゲーム内の架空の相場」という説明を画面に明記。

## ルーレット
- 回転角に22周（7920度）＋当選結果の位置に対応する追加角度を使用する。
- CSSアニメーションの時間は8.5秒、減速の `cubic-bezier(.20,.67,.28,1)` を適用。
- JavaScript側は8.8秒後に回転状態を解除し、当選結果を表示する。
- 当選確率・配当、投入G、停止位置の計算、二重投入の防止機構は維持する。

## 古いスクリーンショットの表示について
ユーザーの画面には「R4.4 COLLECTION & MARKETS」と「NaN%」が出ており、現行のR4.5.1以降のコードが表示されていない。アプリ内WebView・Safariのキャッシュ、古いブラウザタブ、またはGitHub Pages側の反映遅延の可能性がある。原因は未特定。R4.5.2ではページタイトルとUIバージョン、外部JS/CSSのクエリバージョンを更新し、古いキャッシュを利用しにくくした。

## テスト
- 2026年10月23日を基準とする過去7日間の5ジャンル：価格範囲・毎回の決定性・方向転換・30種類以上の異なる指数値を確認。
- 48時間と7日間の全市場および5ジャンル別の描画：線の本数、17/57サンプリング点、`NaN`／`undefined`／`Infinity` が無いことを確認。
- 3,000件の指数取得を模擬し、131msで完了（テスト環境の参考値。スマホ実機性能を保証しない）。
- ルーレットが最低22回転の角度で動作、CSSアニメーション8.5秒、結果確定8.8秒、回転中の重複操作防止を確認。
- **計75項目**の模擬テストを通過。

## 今後の確認
- GitHub Pagesに配信されたHTMLとJS/CSSのバージョンが最新か、iPhone Safariで実際に確認する。
- アプリ内Safariの古いページを開いたままなら、強制再読み込みまたは新しいクエリ付きURLからアクセスする。
- 実機での相場線の視認性とルーレットの演出速度を確認。過度に長いと感じた場合は速度調節やスキップ機能を検討。
