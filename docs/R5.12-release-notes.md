# R5.12 — 廃商業区 2,000×1,600 / 45探索地点 / 完全停止の個別回収

## 概要
廃商業区を新しい2D室内探索の**先行プレイ可能な試作マップ**へ拡張。16の部屋と中央通路・周囲の通路、合計80の壁セグメントを使う。壁は扉幅76pxの通り抜け口を用意。自動ドア演出や鍵は後工程。
新しい出撃に限り **2,000×1,600px**。廃工場・旧遺構と旧途中セーブは従来の920×720px・12宝箱のまま。

## 配置と中身
- 配置候補は60地点、1出撃の有効地点は45。
- **商品棚14、ロッカー10、資材箱8、レジ・引き出し5、木箱4、鉄箱2、金庫2。**
- 各種の個数は固定、同種候補から抽選するため場所が変わる。店舗ごとに「スポーツ用品店」「ホームセンター」「ドラッグストア」「宝飾店」などのテーマを付けた。
- 棚1–2個、ロッカー2–3個、箱1–3個、レジ1–2個、木箱2–3個、鉄箱2–3個、金庫1–2個。中身は探索開始時に個々のアイテムID・品質まで決定。
- 出現レア度の仮重みは `exploration.js > containerReward` にまとめた（一般棚でSR以上約3%、金庫でSR以上約55%）。既存ガチャ確率は変更なし。
- 部屋のテーマに合うカテゴリは、同レア度内で約4倍の抽選重み。特定アイテムの入手保証ではない。
- **同じ容器を開き直しても再抽選されない。** 回収するとその品だけ減り、残りの品は同じ場所に保存される。空の棚は再補充されない。

## 操作と完全停止
- 近づいて「調べる」→アイテムごとの「取る」→「探索に戻る」。
- 回収選択中はプレイヤー移動・敵AI・攻撃・時間経過が完全停止。`run.paused` と既存の停止時刻補正を再利用。
- 敵が追跡・攻撃準備中で、プレイヤーとの距離115px未満の場合は新しく開けない（その場で停止を乱用できないようにする）。
- タッチ領域は46px以上、スクロール可能なコンパクトリスト。画面外の背景は操作を受け付けない。
- 選んだアイテムは `run.loot` に入り、同時に容器の `contents` から消える。両方を同一チェックポイントに記録し、`saveWithCommit` 完了後に画面を更新。

## セーブと旧バージョン
- メインストレージのVERSIONやキー、`state.exploreRun.v=1` は変更せず、追加フィールド `mapVersion:2` と `containers` を保存。
- 新マップを読み込むと2000×1600の壁を選択し、旧マップの途中セーブを読み込むと旧920×720と従来の障害物へ戻す。
- チェックポイント復元時に45地点・種類・ID・位置・報酬形式・重複を検証する。
- セーブ時刻から探索の残り時間が進行しない既存の復元方式を維持。回収メニューを開いたまま再読み込みすると、**選択中の品は保存されたまま、通常の一時停止画面から復帰**する。
- 既存の装備・ロスト・安全ポーチ（最大2点）・ガチャ・相場・アーケードに変更なし。

## 現状の制限・未決定事項
1. **探索時間のルールは未決定**。以前の試作コードにある「4分」が現時点では残っているが、最終仕様ではない。
2. 室内の壁と開口部は実装、扉の開閉アニメーション・鍵付き保管庫・細かな棚障害物・室内専用アートは未実装。
3. 敵はこれまでの3種類のまま。新マップ向けに経路探索（曲がり角での追跡）を実装していないため、室内で壁に引っかかる可能性がある。
4. 廃工場と旧遺構は旧地形のまま。
5. アイテムと部屋は仮の視覚表示。45地点・ドロップ率・経済バランスは今後のプレイテストで調整。
6. iPhone Safari実機の操作テストと本番配信されたブラウザでのE2Eは**未実施**。ゲーム本体へのコード反映と模擬実行の成功を実機確認と区別する。
