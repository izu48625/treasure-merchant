# R5.2.3f — 宝箱の端・影が切れない表示に調整

2026-10-24

## 実機での指摘
通常・歴史・現代・高級の宝箱が、スマホ画面で端や影を切り落としたように見える。

## 原因
`gacha-ui.css` のR5.2.1時点の調整では、640pxの元画像に`object-fit: contain`を指定した**あとで画像をCSS transformで1.34倍に拡大**していた。一方、宝箱の親要素`.tm-vault`は`overflow:hidden`で、表示領域もスマホ向けに圧縮されていた。従って画像の透明余白を超えて外側へ描画される影や宝箱の端をクリップする可能性があった。

## 修正
- 宝箱の表示エリア内の配置領域を上左右・下に少し内側へ寄せた（`inset:3% 4% 14%`）。幅380px以下では `4% 5% 15%`。
- 全宝箱のCSS画像描画に `object-fit:contain`、`object-position:center`、幅・高さ100%・最大100%を適用。
- 拡大率を通常0.99倍、歴史・現代・高級1.20倍に抑制。元は通常1倍、それ以外1.34倍。
- 10連や50連の開封中の表示にも同様の余白を与え、封印解除時の拡大倍率を従来の最大1.26倍から最大1.14倍へ下げた。通常宝箱は1.08倍。
- `gacha-ui.css?v=R5.2.3f` のキャッシュバストとサイト上のバージョン表記を更新。

## 変更しないもの
- 財宝箱の原画（4種×開閉のWebP）
- ガチャの抽選・排出率・天井・所持品・付与・セーブ・タスクキル復元
- ボタン、チケット表示、種類選択、ガチャ実行フロー
- カードのレア色・所持品一覧のサイズ

## 確認
- CSSの括弧整合性を検証。
- 本体のインラインJavaScript構文検証。
- `gacha()` と `saveWithCommit()` は修正前と同一。
- 宝箱画像の外観はユーザー実機画像を元に調整したが、**改修後のiPhone Safari表示は未実機検証**。最終判断には4種類を切り替えた画面の比較が必要。
