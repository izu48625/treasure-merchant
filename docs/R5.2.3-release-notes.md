# R5.2.3 — コレクション導線・全レア共通鑑定カード

2026-10-24

## 変更概要
1. 所持品と図鑑に常時表示の2タブを設置（`collection-ui.js`/`collection-ui.css`）。既存の `gallery()` / `inventory()` は書き換えずに再利用。図鑑表示中も固定ナビの「所持品」を選択状態にする。ホーム／ガチャからの従来の図鑑リンクも維持。
2. レア度N/C/R/SR/SSR/UR/EX用の**静的SVGフレーム7枚＋共通基準SVG1枚**を `assets/cards/` に配置。すべて 360×520 の同じ座標・縁の形・画像窓で制作し、材質、装飾密度と線の配色のみ変更。
3. `treasure-card.js`と`treasure-card.css`を作成。共通の `treasureCard(it,q,options)` はレア度、番号、名前、画像、分類、品質、価値を描画するだけでゲーム状態を変更しない。
4. `gacha-ui.js`の `gachaDossierCard` は新しい共通カードに委譲。従来の10連・50連結果のタップ詳細、周回ボタンはそのまま。共通カードJS読み込み失敗時には単純表示のフォールバックを持つ。
5. `index.html`の`detailHTML()` と `groupDetailHTML()` に共通カードを表示し、その下に従来の品質・相場・売却・保護・複製・同品質の個体管理を維持。図鑑から開いた詳細も同じカードを利用する。
6. モーダル内はカードと操作ボタンが重ならないよう、詳細部分をスクロールさせ、操作ボタンはカードの後段に配置する。ガチャ結果モーダルの旧stickyボタンを相対配置に変更。

## カードの確定ルール
- 論理キャンバス360×520、画像窓・レア欄・タイトル・品質/価値・フッターの位置は完全共通。
- SSR＝深紅／赤銅、UR＝黄金／黒、EX＝黒紫／白金。EXも切り欠きで外形を変えず、装飾で差別化する。
- 追加アニメーションなし。細かな光・影は静的なCSSのみ。
- すべて既存の財宝IDと品質を参照。描画中の再抽選や再付与は行わない。

## 既存ゲーム機能の保護
- 抽選、天井、開封時セーブ、所持品の選別、図鑑データ、売却・保護・複製等の実行ロジックは無変更。
- `inventory()`、`gallery()`、`gacha(type,count,mode)`、`gachaRevealValid()`、`saveWithCommit()`を旧R5.2.2ベースラインに対して文字列レベルで比較し同一性を確認。
- 状態に新たな必須プロパティを追加しないので旧セーブとの互換性を保持する。

## 実施した確認
- JS構文：`index.html`のメインスクリプト、`gacha-ui.js`、`treasure-card.js`、`collection-ui.js`が通過。
- SVG8枚の登録／全フレームの`viewBox="0 0 360 520"`一致。
- レア度7段階×所持品詳細／まとめ画面／図鑑画面の21ケースをモックで表示・操作導線確認。
- 所持品詳細の売却・保護ボタンとまとめ画面の売却機能がHTMLに保持されている。
- CSSの括弧整合性とJS読み込み順の検証。
