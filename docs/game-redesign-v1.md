# Treasure Merchant — 探索主体への再設計仕様 v1 (2026-10-25)

## 方針
既存のガチャ・財宝・所持品・図鑑・市場・遊技場・宝箱画像・セーブを維持しつつ、探索→持ち帰り→売却/分解/製作/強化→自動ボス攻略→新区域解放を主循環にする。世界観は現代の危険な封鎖区域を基礎とし、後半に異常エネルギー改造武器、SF装備、伝説的遺物を段階導入。危険な探索と安全な商会拠点を対比させる。

## 現行確認
main の exploration.js は4分・宝箱12・円形敵・自動攻撃・装備3枠・脱出時に既存 receive/saveWithCommit を使う独立MVP。現状の死亡/時間切れ/離脱は未確定戦利品だけ消失、持込装備は維持。実機Safari・永続化障害・長期耐久は未検証。既存システムを破壊せず独立モジュールを段階追加する。

## 確定方向
- 探索: 2D見下ろし、移動手動、通常攻撃オートを初期ON、手動攻撃はいつでも優先、回避/スキルは手動。序盤は少数敵、時間経過で敵増加する中間テンポ。
- 装備: 金属バット、レンチ、ハンマー、ヌンチャク、チェーンソー等の日用品を武器化。攻撃アーキタイプを共有（打撃/薙ぎ/突き/連撃/継続/射撃/投擲）。装備価値と市場価格を分離。
- 成長: 安価な基本製作、小幅強化(+0〜+5を仮置き)、モンハン型の分岐派生。炎バット/雷チェーンソー/レーザー銃/ロボットアーム/反重力ソード等は後半に解放。完成品のドロップ/ガチャと素材製作を併存。
- アイテム必須性: 通常品も使用・売却・分解・納品・拠点改修に用途。強い派生には探索限定素材とボス素材を必要とする。重複ガチャ品にも分解価値を与える。売買/分解だけで無限増殖できない経済にする。
- リスク: 探索死亡/時間切れで未確定戦利品および持込装備をロスト。安全ポーチ初期2枠(仮)は小型品/素材/券のみ保護し、装備中武器・大型財宝は不可。レシピ解放・図鑑・拠点は永続。無一文時の安価/無料再起装備を保証。
- ボス: 探索とは別の装備・ステータス・相性による自動シミュレーション。開始時にシード/結果を確定保存し、1x/2x/4x/スキップは演出だけ変更。初期はボス戦装備ロストなし、報酬/挑戦コストは要調整。討伐で次の探索区域を解放。
- ガチャ: 財宝ガチャと装備ガチャの両方を維持/導入。共通アイテムIDで管理し、排出対象/重みを分ける。探索・ボス限定素材はガチャで代替不可。既存4種宝箱演出は活用。
- マップ: 現代の廃商業施設/工場/地下施設から始め、後半は異常現象・先端技術・伝説遺物へ。エリア別のアイテムテーブル、敵、ボス、素材を持つ。
- 拠点: 倉庫/装備/製作・強化/市場/ガチャ/図鑑/ボス/娯楽。ゲームの主導線は「探索」「装備」「ボス」優先。既存の市場・遊技場は削除しない。

## 設計上の保護
1. アイテム定義と所有インスタンスを分離。インスタンスUID、品質、強化段階、派生ID、耐久、ロック/保護状態を扱う。既存の inv 構造を直接破壊しないアダプタ/マイグレーションを先に設計。
2. 出撃時の装備・ポーチ内容・戦利品・抽選シードを保存。出撃/回収/死亡を二重精算しないトランザクション設計。画面移動/タスクキル時の扱いは「復帰または明示的な失敗」で統一し、抜け道を作らない。
3. 戦闘の計算ロジックと描画/演出を分離。手動攻撃はオートと同一基礎威力で対象・方向・タイミングを優先する。
4. 売却済み/ロスト済みUIDの装備参照を解消し、所持品・図鑑・市場・ガチャの旧セーブを保全。
5. ボス報酬は確定保存後に一度だけ付与。ゲーム内通貨・素材消費も重複処理禁止。
6. 初期は課金/広告/オンライン機能を追加しない。iPhone Safariを優先。

## 追加決定：短時間ガチャと長時間探索の二重プレイスタイル（v1.1）
- 主導線は「探索・ガチャ・装備・ボス」。探索を主目的にしつつ、ガチャを単なる付属ではなく独立した短時間の遊びにする。
- 30秒: 財宝ガチャを10/50/100連で回す、結果を一括確認、新規図鑑/最高レアのみ強調。3分: 分解・装備製作・強化・自動ボス。5〜10分: 探索・撤退。
- ガチャは「演出鑑定」と「高速周回」を切替可能。高速周回は抽選結果を最初に確定し、表示だけスキップする。結果画面に「同条件でもう一度」を置き、押しっぱなし自動連打・無限自動消費は初期版では採用しない。
- 通常財宝ガチャは大量周回向け、装備ガチャは基本装備の調達、希少ガチャは低頻度。高レアの獲得演出・新規図鑑を残し、重複は売却/分解の候補にできる。
- 自動整理は初期OFF、保護品/初獲得品/高レア/装備中/派生素材候補を誤処分しない。結果は新規・希少・素材・重複の集計で見せ、所持上限/大量処理性能を検証。
- ガチャ品は基本製作・小幅強化・コレクション・資金に役立つ。一方、新区域・特殊派生に必要な探索限定/ボス限定素材はガチャのみでは入手できない。ガチャだけの日も緩やかに成長できるが、探索を代替しない。
- 経済: ガチャの購入→排出品売却/分解→再ガチャの循環で無限増殖を許さない。期待売却額、分解換算、券配布量、レア排出率を一体でシミュレーションして決める。既存の無料試験ガチャは本番経済と混同しない。
- 安全性: 10/50/100連は一括確定・一度だけ通貨/券消費・一度だけ付与。タスクキル後は同じ結果を復元。重複タップ、通信遅延、容量不足、セーブ失敗を想定した処理。広告視聴・課金・オンライン依存は導入しない。
- UI: モバイル片手操作を重視。ガチャ画面の主要ボタン（10/50/100、演出ON/OFF、結果、再実行）は一画面に配置。探索の操作領域と混同しない。ガチャ結果は100件のカード全表示を避け、集計＋注目品だけを先に表示。
- 実装順: P0に既存ガチャの抽選/所持/セーブの監査を追加。P1と並行してガチャ高速周回UIの独立プロトタイプを作る。P5で財宝/装備ガチャと経済統合を完了する。既存ガチャ演出・抽選は互換性を維持する。
- 未確定: ガチャ券/通貨の恒常供給方法、ガチャ種類ごとの排出確率、連数上限、処分自動化の保護条件。実装前に数値調整とテストを行う。

## 探索マップ設計 B案：半ランダム生成（2026-10-25）
- 探索は区域選択式。区域ごとに固定の世界観・部屋テンプレート・敵/宝箱/素材テーブルを持つ。部屋の接続・敵・宝箱・イベント・脱出候補を出撃シードで変える。
- 初期マップは8〜12部屋、15〜20種類の部屋テンプレートを想定（仮値）。部屋は出撃/通路/広場/店舗/倉庫/危険室/特別室/出口等のタグで管理。マップ構造は接続グラフで生成し、描画座標に配置する。
- 生成時に必ず出撃地点から全必須地点へ到達できること、最低1つの脱出路があること、出撃周辺が安全であること、行き止まりと危険室が偏りすぎないことを検証。生成失敗時は固定フォールバック配置。
- 初期区域候補: 廃商業地区→放棄工業地帯→封鎖研究施設→異常汚染地区→深層隔離区域。区域ごとに素材・敵・環境ギミック・武器派生解放を紐付ける。区域名と総数は仮。
- 通常脱出は出撃地点への帰還で常時利用可能。条件付き脱出は鍵/電源等の条件を満たして開通し、帰還経路を短縮。緊急脱出は将来の消耗品案として保留。
- タイムリミットは区域別に調整、初期4〜7分を試験範囲とする。時間経過で敵が増え、長居の期待報酬と危険度が上がる。撤退判断をプレイヤーに委ねる。
- 宝箱/素材は部屋タグに従い配置。特別室1〜2、希少素材は高危険の部屋で得やすくする。バッグ容量・安全ポーチ・装備ロストと接続。
- ミニマップは既訪問部屋を明示し、出口と現在位置を分かりやすく表示。未探索の希少報酬位置は表示しない。部屋の再訪と分岐判断をサポート。
- 初期実装は固定マップにランダムな宝箱/敵配置→テンプレート接続生成→出口条件と特殊室→区域追加の順。出撃シードを保存して復元可能にする。
- 検証項目: 生成1000回以上の到達可能性/出口保証/敵密度/初期安全、スマホ操作時の通路幅と衝突、脱出処理の二重精算、タスクキル復帰。

## 装備スロット決定：B案 標準7枠（2026-10-25）
ユーザー決定: メイン武器1、サブ武器1、頭防具1、胴防具1、脚防具1、アクセサリー1、探索道具1。探索中の武器切替はワンタップ。メイン/サブ武器の使い分けを戦闘の中心にする。アクセサリーは常時補正、探索道具は能動的な探索機能として区別。防具は防御以外に移動や耐性等の特性を持たせる。
探索死亡/時間切れ時は持込7枠を原則ロスト対象とするが、装備インスタンス単位で確実に精算し、最低限の再出撃手段を確保。装備耐久度は初期導入を保留。武器種/攻撃モーション/ステータス/強化派生/持ち替えクールダウン等の細則は次の設計対象。

## R5.5a 実装状況（2026-10-26）

## R5.5b 実装状況（2026-10-26）
- [x] メイン／サブ武器を所持品UIDに紐付ける独立した2スロットとして実装。既存 `exploreEquip.weapon` はメインのまま維持し、`weapon2` を互換追加。選択UI・一時停止中の変更に対応。同じアイテムUIDを両スロットに装着できない（別UIDの重複品は可）。
- [x] 攻撃アーキタイプ3種：打撃（射程64px、扇形±1.08rad、間隔0.77秒、威力×1.35、最大2体、重装以外へ微ノックバック）、連撃（射程49px、±0.72rad、間隔0.30秒、威力×0.72、単体）、長射程（射程104px、±0.36rad、間隔0.72秒、威力×1.00、単体）。装備なし時は素手（射程43px、間隔0.62秒）。
