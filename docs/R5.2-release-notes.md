# R5.2 — ガチャ宝箱の画像素材・開封3段階

2026-10-24

## 実装
- 「通常」「歴史」「現代」「高級」鑑定の宝箱について、閉じた状態・開封途中・開封後の透過WebP 12点（640×480）を `assets/gacha/frames/` に収録。
- 鑑定室の待機画面／開封開始前に `closed.webp` を表示。
- 開封ボタンを押して抽選結果の公開ステップが保存された後、結果画面を一時的に覆う専用演出を表示し、`closed → opening → open` と切り替える。閉じた画面は復旧時にも同じ画像。
- 現行のガチャ抽選・天井・価格・財宝付与・セーブ・途中開封復元・10/50連・即表示モードを維持。通常鑑定にも新しいWebPを追加し、SVGは画像読み込み失敗時の代替として残す。
- ユーザーがOSのモーション軽減を設定していればアニメーション量を削減する。
- WebPが読み込めない場合は以前のSVG画像を表示する。
- 画像とゲームロジックを分離し、実機評価を踏まえて今後素材だけ差し替えられる設計。

## 検査
- WebP12枚：ローカルのGit blob SHA-1とGitHub登録ファイルのSHAが一致（ファイルサイズ約33〜62KB）。
- `gacha-ui.js` と `index.html` のインラインJavaScript構文確認。
- ガチャ4種類の画面生成／1・10・50連の未開封・個別表示・一覧表示のモックチェックが通過。
- 現行 `function gacha()` がR5.1と文字列レベルで同一。レアリティ抽選、品質、アイテム選定は変更なし。
- CSSの中括弧整合と既存のsaveWithCommit完了後表示を確認。
- **iPhone Safari実機での視覚確認・連打・中断・タスクキル・画像の実機読み込みテストは未実施**。
