# R5.9 装備280種 × ジョブ21枠 バランス監査（2026-10-28）

状態: **設計値の静的監査・試算完了。本体コード未変更。**

## 監査対象・計算方法
- 装備マスター `docs/R5.9-equipment-master-280-draft.csv`: 全280件（武器160、頭28、胴28、脚24、アクセサリー24、探索道具16）。
- ジョブ: 初期「一般人」＋追加20職の21種。武器160×ジョブ21＝**3,360組**を検証。
- 原則として中品質（倍率1）、強化+0を比較。追加で最高品質（1.15倍）、強化+5（1.30倍）を組み合わせた上限確認も実施。傭兵の+10%はHP50%以下の**条件成立時だけ**の比較である。
- 武器ダメージを `attack = min(150, floor(baseAttack * quality * enhancement * (1+jobBonus) + .5))`; `hitDamage = floor(attack * stylePower * enemyAffinity + .5)`; `singleDPS = hitDamage / interval` として整数丸めを再現する。複数体にヒットして得られる総ダメージ、出血・ひるみ・属性・ノックバック・防御・装備耐久等の効果は含めない。
- 現行ゲームの相性: 打撃対重装1.22倍 / 連撃対高速1.22倍 / 長射程対通常1.15倍を、該当敵の最短撃破時間にだけ適用。他の新系統には**仮に相性補正なし**。
- 最短撃破時間は攻撃範囲内・全弾命中・初撃時刻t=0の理論値: `max(0,ceil(enemyHP/hitDamage)-1)*interval`。**AIシミュレーション、PvE実機プレイ、勝率・生存率の試験ではない。**

## 開発上の重要な発見・推奨修正
1. **序盤の敵が現行HPでは速く倒されすぎる可能性が高い。** 金属バットの1撃27、現行通常敵HP35なら最短0.80秒、重装敵HP94なら打撃相性込み最短1.60秒。設計目標の通常1.5〜3秒、重装4〜8秒を満たさない。新区域向けの試験値として序盤通常HP70、重装HP180を検討（同じ条件で1.60秒・4.00秒）。現行マップの敵HP変更は実機試験後に判断する。
2. **連撃＋整備士の端数増幅を監査。** チェーンソーは+12%の職補正が実効DPS+17.6%。現在のモデルでは許容範囲だが、1撃整数丸めで武器格差が急変しやすい。必要なら内部ダメージを小数蓄積する方式を検討。
3. **防御の軽減効果が重複すると職の個性が消える。** 物理50%を最終上限とし、同一種の防具耐性を単純加算しない。キャッチャーは物理軽減以外の特性に変更検討。
4. **職業のうち現実装可能な効果と将来用を区別。** 医師・看護師・料理人・研究者・怪盗・探検家・考古学者の主能力は関連システム待ち。職業ガチャに投入する前に効果を実装するか、解放を保留する。
5. **新武器スタイルは未対応。** 現行 `WEAPON_STYLES` には strike / rapid / reach / unarmed のみ。masterにある slash/whip/machine/ranged/special は新戦闘エンジンへ接続が必要。記載DPSが実機で出るとは現時点では言えない。
6. **メタデータに解釈の余地あり。** 「大工＝全strike＋tool」「剣道家＝名前に『竹刀・木刀・刀』を含む」「清掃員＝名前による対象判定」は試算用の仮ルール。実装前に装備に安定した `tags[]` を割り振り、ID固定で判定すること。
7. **最高品質+5の余力は少ない武器もある。** 最大215.22 DPSは監査目安220に近いため、今後の属性/セット/熟練度/ボス特効を追加した際の再監査が必要。220は全武器へのハードキャップではなく監査警戒値。
