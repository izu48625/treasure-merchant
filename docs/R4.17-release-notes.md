# R4.17 — 財宝商会ビジュアル刷新／遊技場無料モード廃止

更新日：2026-10-24

## 目的
「カードと四角いボタンが並ぶだけの試作UI」の印象を弱め、古い財宝商会のような質感を追加。ガチャの開封、ルーレットの回転、スロットの停止・当選がより印象に残るようにする。スマートフォンで繰り返し遊びやすいコンパクトな配置を維持する。

## 実装
1. `visual-polish.css` 新設。黒漆・古い真鍮・琥珀色を基調にトップバー、ホームの資産表示、パネル、ボタン、下部ナビ、ガチャ、遊技場を統一。単なる青灰色UIの反復から脱却。
2. ガチャ結果画面に光の筋、宝箱の浮遊、開封時のスケール・フェード、高レア別の金／赤／琥珀演出を追加。排出財宝データは確定済み保存値を参照するだけで再抽選なし。まとめ表示と即表示のボタンは維持。
3. ルーレット盤に二重の金属縁、重厚なハブ、強い輪郭・影・回転中の照明を追加。回転時間、事前封印、回転終了後の保存は維持。
4. スロットに金属筐体・リール窓・STOPボタンを追加。リールの循環アニメーションを絵柄5個の高さに一致させる。プレイヤーのSTOPは封印済みリールを公開するだけ。
5. ルーレット／スロット／財宝勝負の直前結果を背景と発光で強調。賭け金の5択／周回／一括STOPはそのまま。
6. 商会遊技場の「無料チャレンジ」をUI・イベント分岐・抽選機能から撤去、モード選択を3列に。旧セーブ `arcadeFreeDay` フィールドは意図的に維持し、セーブ移行不要・既存プレイデータを保護。ガチャの「初回限定・無料10連」は別機能として維持。

## 変更ファイル
- `visual-polish.css`：新デザインのスタイルとアニメーションを独立管理。
- `arcade.js`：無料財宝チャレンジを削除、3モード化。既存抽選・保存・払い戻し処理はそのまま。
- `index.html`：新CSSをバージョン付きで読み込み、ガチャ鑑定表示や実装文言を変更。セーブ互換性のある `VERSION` とストレージキーは据え置き。
- `README.md`：R4.17を最新として案内。

## 監査・検証
- 新旧 `arcade.js` の関数を比較。削除した関数は `arcadeToday`, `arcadeFree`, `arcadeFreeView` の3つのみ。
- `arcadeSealReward`, `arcadeSealedRewardValid`, `arcadeLegacyReward`, `arcadeAwardSealed` を保持。ルーレット・スロットの結果確定、報酬付与、保存待機の関数と内容を維持。
- JavaScript構文検証：`arcade.js` と `index.html` 内スクリプトともPASS。
- 旧ガチャ開封途中セーブ、`gachaReveal`, `lastGacha`, `saveWithCommit` のコードを維持したことを静的確認。
- アニメーションを減らす設定（`prefers-reduced-motion`）に対応。演出の追加はJSのタイマー追加やゲーム抽選を伴わない。
- **未検証**：iPhone実機での見た目・タッチ応答、OSタスクキル、容量上限／多タブ競合、実画面のピクセルテスト。CSS・静的監査のみで完全動作を保証しない。
