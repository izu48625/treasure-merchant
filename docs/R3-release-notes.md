# R3 — ガチャ保証・10連一覧・資産グラフ

更新：2026-10-21

## ユーザー要望の反映
1. **高級ガチャ**：10連専用。10個のうち1個をUR以上確定（UR90% / EX10%）、残り9個は通常ガチャと同じ基礎排出率。必要金額は **650,000 G/10連**。確定枠のUR/EX比は従来の通常抽選内のUR:EX＝450:50に基づく。高級ガチャの旧倍率補正は廃止。
2. **通常ガチャ**：単発・10連・初回無料・デモ広告報酬の合算で、10回以内にSR以上1個を保証。SR以上を自然排出した場合は天井カウンターを0に戻す。天井以外の基礎確率は変更なし。年代別と高級は通常ガチャの天井カウント対象外。
3. **10連結果**：iPhone相当の画面で、2列×5行のコンパクト表示。画像・レア・アイテム名・品質・価格を1画面にまとめる。PCでは5列×2行。開封アニメと個別鑑定は継続。
4. **資産グラフ**：総資産・アイテム資産・現金・日別利益の4タブ。グラフ切替は画面再読込不要。

## 日別利益の定義
その日の **現金＋所持品評価額の変化** を暫定的な損益として表示する。単なる売却代金は利益ではない。市場の時価変動やガチャの支出・獲得品評価を含む。原価ベースの実現損益とは異なる（正式版で追加検討）。

新しい日次記録 `dailyHistory` と、時刻別残高 `history[].c`（現金）・`history[].items`（所持品時価）を記録。旧R1/R2の残高内訳は遡及復元できないため、R3以後から記録する。日次データは直近45記録日、時刻別は直近240記録点を保持。

## 互換性
- セーブキー `treasure-exchange-demo-r1`、バージョン `v:1` は維持。
- 旧セーブには `normalPity:0`・`dailyHistory:[]` を追加して利用。
- 既存の所持品・図鑑・現金は保持。初期化しない。

## 検証
- JavaScript `node --check` 通過。
- 実コードを用いた自動ロジックテスト：通常10回天井、通常単発の累積天井、高級10連UR確定（確定枠以外は基礎確率）、結果カード10枚、4タブ、売却後の純資産一致、翌日の履歴生成。
- **制約**：自動ブラウザ環境ではページ表示がブロックされ、iPhone Safariの実機表示は未確認。10連1画面配置はCSS上の対応。公開URLで実機確認を要する。
