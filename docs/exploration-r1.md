# 探索フィールド R1（試作）

既存の財宝商会に加える、2D見下ろし型の脱出・戦利品収集モード。

## 操作
- スマートフォン：左下の仮想スティックで移動、「宝箱を開ける」「脱出する」をタップ。
- PC：WASD/方向キーで移動、スペースで宝箱、Eで脱出。
- 敵は接近してきて接触ダメージを与える。プレイヤーの攻撃は範囲内の敵に自動発動。
- 途中で別画面に移ると探索時間は一時停止。

## 試作バランス
- 制限時間150秒、HP6、マップ1種類、宝箱12個、丸型追尾敵。
- 敵は時間経過で増加（最大24体）。
- 時間切れ・HP0ではその探索中の戦利品のみ喪失。既存の所持品・現金は安全。
- 宝箱の結果（ID・品質・ガチャ券の有無）は開始時に決定して保存する。再読込時に引き直さない。
- ガチャ券は各箱8%で付属（試作値）。脱出時にだけ追加権利を付与する。
- 武器枠は既存の所持品内の適格アイテムから選択。レア度・品質で自動攻撃の威力が変わる。
- アイテムの既存画像、4種類の閉宝箱画像、既存相場、図鑑を再利用する。
- 入手数の由来は `disc.exploreQty` に記録し、ガチャの `gachaQty` に加算しない。

## データ保護
- `exploreRun` は現行セーブのメタデータ内に保存する。報酬は帰還時の `receive` と `saveWithCommit` で確定。
- 旧ガチャ・スロットの抽選、途中結果、払い戻し処理は変更しない。
- 現状はオフライン・端末内保存の試作であり、サーバー検証や不正対策は未実装。
- 再開時はプレイヤー位置・HP・時間・開封済みの箱を復元するが、敵の具体的な位置は再生成する。
- 通常ガチャは現行の無料テスト設定が継続するため、ガチャ券の経済的な意味は正式版に向けて調整が必要。

## 確認済み
- JavaScriptの構文解析（既存index、探索モジュール）。
- 試験用の模擬環境において、開始時の事前抽選・二重開始防止・脱出時の報酬確定・ガチャ券・由来記録・重複受取防止・時間切れ時の戦利品消失。
- 4種類の画像パスのリポジトリ内存在確認。

- 長期の難易度バランス調整、性能測定、実機タッチ判定。
