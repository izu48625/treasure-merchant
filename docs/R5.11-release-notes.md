# R5.11 — 先行装備22種と個別ステータス調整（2026-10-28）

## 実装範囲
R5.9の280種マスターから22種類だけを選び、**ガチャ・探索報酬・図鑑・所持品・探索装備**に登録した。
- 武器10: 釘バット / 竹刀 / 木刀 / 物干し竿 / パイプレンチ / 包丁 / チェーン / チェーンソー / 投げナイフ / 電撃チェーン
- 防具10: キャッチャーマスク・プロテクター・レガース、剣道面・胴・垂、消防ヘルメット・消防服・消防ブーツ、ランニングシューズ
- 道具2: 小型リュック、大型登山リュック

装備のマスターIDはEQ-xxxxを維持。新しい財宝IDはITM-(300+装備マスターの連番)、例: EQ-0003 → ITM-00303。既存ITM-00001〜00020のIDは不変。初回は**仮SVG画像**であり、専用の装備イラストは未制作。

## 技術的変更
- `equipment-pilot.js`: 22装備の定義（名前、レア度、価格、重量、部位、攻撃、間隔、射程、同時対象数、HP/DEF/速度/運搬、限定的な特殊効果）。元データ: `docs/R5.9-equipment-master-280-draft.csv`。
- `index.html`: 旧 `ITEMS` を変更せず `ITEMS.push(...TreasureEquipmentPilot.items)`、ID辞書を組み立てる前に22件を追加。通常のガチャ・探索ドロップに参加する。**レア度抽選の重みは不変だが、同一レア度内の各既存アイテムの相対的な当たりやすさは低下**。高級ガチャのUR/EX確定と50/100天井のルールは変更なし。
- `exploration.js`: 新装備だけ装備マスターを優先。武器固有の攻撃間隔/射程/角度/最大対象数、品質別攻撃力0.95/1/1.07/1.15、防具のHP/DEF/速度と部位耐性のうち最高値、リュック運搬量+4kg/+8kgを適用。探索バッグへ入れた時のアイテム重量も個別反映。
- `combat-rules.js`: optional pattern引数で装備固有範囲判定。現行の斬撃/鞭効果に加え、個別の出血（DOT値1〜6の範囲で保存復帰）、鈍足、感電（移動低下）、ひるみ（短い移動低下）に対応。パイプレンチは重装敵へのダメージ加算を装備に限定。
- 新規装備が出撃に含まれる場合のみ `combatRulesVersion:2` とし、DEF/(DEF+20)の軽減式・物理軽減50%上限、正面/近接への追加軽減を上限内で適用。旧装備のみの出撃・既存途中セーブでは従来の固定値防御（最大12減算）を保持。旧保存スキーマ `v:1` を維持し、不要なセーブ移行は行っていない。
- `exploration.css`: 選択済みの先行装備のみ、数値をコンパクトに表示。iPhoneで折り返し可能。
