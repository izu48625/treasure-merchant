# R4.4.1 — 公開前の品質修正と回帰検証

更新: 2026-10-23

## 変更
- **市場グラフ**：R4.4で3時間刻みにした後も、最後の値だけ旧48/168要素目を参照していたため、騰落率が `NaN%` になりうる不具合を修正。`vals[vals.length-1]` に統一。
- 市場グラフのアクセシビリティ用説明文を「48時間／7日間」の選択内容に一致させた。
- **商会ルーレット**：回転終了後に円盤が初期角度へ戻る挙動を修正。当選マスに針を残し、次回もその停止角度から3回転以上するように変更。抽選確率の内訳は変更なし。
- **商会スロット**：リール停止後に固定絵柄へ戻らず、抽選された3絵柄が表示されたままになるよう修正。
- **無料財宝チャレンジ**：1日1回の制限を、テスト用の「時刻を進める」機能とは独立した端末の実際のローカル日付で計算。旧セーブの `arcadeFreeDay` フィールドは維持。
- **財宝大勝負**：投入して消滅した財宝が、所持品の「一括売却用選択」に残らないようにした。図鑑登録・過去の品質記録は従来どおり永久保持。
- **投入カード**：スマホ2列のまま、−／＋／全ボタンのタップ領域を34×34pxへ拡大。
- HTMLの外部JS/CSSにクエリバージョンを付け直し、古いキャッシュが残りにくいようにした。
- バージョン表記をR4.4.1へ更新。

## 実施した検証
1. JS統合構文確認。
2. 模擬起動と旧セーブ形式の読み込み。
3. 世界TOP30／日本TOP30、称号画面のタブ切替。
4. ガチャ50回・100回保証の周期。
5. 市場「48時間=17点・7日間=57点」、全体および個別3ジャンル、`NaN`／`undefined`がないこと。
6. 財宝大勝負で敗北後の所持品消滅と図鑑履歴の保持。
7. 無料抽選で時刻進行をしても2度目を引けないことと、JSON保存への日付記録。
8. ルーレットでG支払・アニメ中二重実行禁止・最終位置保持・2回連続の停止位置。
9. スロットで停止後にも当選絵柄を保持すること。
10. CSS回転角の開始値と終了値、アニメ軽減設定。

市場グラフ中心の31項目、ルーレット・スロット停止演出の8項目を模擬チェック済み。別の統合検証は38項目まで通過したが、検証用タイマーキューでトースト終了処理と抽選アニメ終了処理が混在したため一旦停止し、抽選タイマーを識別する8項目の修正テストを通過している（製品バグではない）。
