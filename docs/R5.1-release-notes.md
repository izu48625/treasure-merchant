# 財宝商会 R5.1 — 財宝鑑定室・ガチャ画面の改修

更新日：2026-10-24

## 目的
R5.0で完成見本となったスロット同様、ガチャの絵文字・均等カード・ボタン主体の「Web機能」から、専用装置を中心にした「ゲーム画面」に移行する。既存のガチャ抽選・確率・天井・獲得品・保存処理は一切変更しない。

## 変更内容
- 新規 `assets/gacha/chest-normal.svg`、`chest-era.svg`、`chest-modern.svg`、`chest-lux.svg`：商会の鑑定箱／古い封印箱／現代の保管箱／王家の封印金庫を、それぞれ専用のSVGとして追加。
- `gacha-ui.js`：ガチャ種別タブ、中央の専用鑑定台、1/10/50連、初回無料10連、SR・SSR保証カウンタ、無料テスト表示、即表示切替、実験的なサウンドON/OFFのUIを提供。
- `gacha-ui.css`：鑑定台・宝箱・大きな操作ボタン・封印モーダル・レア別の結果演出・10/50連結果一覧を専用デザインで実装。
- 結果表示では、実際に当選した財宝の既存画像・レアリティ・品質・価格を大きく見せる。SSR/UR/EXは明確に異なる配色・演出とする。
- 10連・50連の結果一覧はコンパクトな収集カードで並べる。直前ガチャの同条件再実行は保持。
- 音は初期OFF。利用者が明示的にONにした場合のみWeb Audioの効果音を鳴らす。音設定は別途 `localStorage` キー `treasure-appraisal-ui-v1` に保存。ゲームデータには追加しない。
- `draw()`、`pullHTML()` の既存実装はフォールバック用に残し、新UIの表示関数へ委譲。新UIのスクリプトが使えないときは旧表示に戻る構造。
- 表示・アニメーション用スクリプトは結果抽選をせず、アイテムは現在の `lastPull`／`gachaReveal` のみから描画する。

## 不変条件
- 通常・歴史・現代・高級（高級は10連専用）と、1/10/50回抽選。
- 50回目SR以上・100回目SSR以上の保証。高級10連の1枠UR以上（UR99%／EX1%）。
- ガチャ権利、G残高、初回無料10連、一度きりの `freeUsed`。
- ガチャ開始時にアイテム・品質・開封状態を保存する `saveWithCommit()`、進捗を保存してから次の画面を出す処理。
- 途中再起動時の開封・結果一覧・同条件の周回を維持。
- 50連は現行どおり結果一覧を即表示。ユーザーが「即表示」を選んだ場合も保存済み結果を出す。

## 検証
- JavaScript構文：`index.html` 内インラインスクリプト、`gacha-ui.js` を検証。
- 旧R5.0と現R5.1の `function gacha()`（抽選＋払い戻し）および `gachaRevealValid()` が文字列レベルで同一と確認。
- 新UIの模擬表示：ガチャ種別4種、1/10/50連それぞれの未開封・個別表示・結果一覧で期待するコントロールと財宝数を確認。
- `gacha-ui.css` の括弧整合性、スクリプトの読込順を静的確認。
- **iPhone Safari実機でのデザイン・操作・長時間周回・アプリタスクキル試験は未実施**。実機検証なしで完成品質とは扱わない。
