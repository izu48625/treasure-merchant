# R5.13 — 閉鎖商業施設の大型迷路マップ（2026-10-28）

## コンセプト
「店舗ごとの別アートを大量制作する」のではなく、**商業施設の閉鎖された売場・倉庫・サービス通路**で世界観と床・壁・什器の素材を統一。奥で価値の高いものを拾うほど、複雑な道を自力で戻る選択になる設計。

## マップ設計
- 新規「廃商業区」出撃のみ **3600×2600px**。以前の2000×1600（R5.12）の約2.93倍、当初920×720の約14倍。
- 幅・高さがわずかに異なる **48区画（8列×6行）**。接続は52以上の扉・通路に限定した連結グラフで管理し、長い曲がり角、行き止まり、分岐と短い周回路を構成。直線で全域を横断する設計にはしない。
- 区画の壁・扉（112px程度）と出入口座標は固定。ゲームプレイで構造を覚えられる。アイテムだけ出撃ごとに配置変更。
- **144の候補地点から80地点を選択**。陳列棚28、ロッカー18、資材箱14、作業台7、木製宝箱7、鉄製宝箱4、金庫2。R5.12の45地点から増加。
- 高レア容器の候補地点は出口から遠い区画を優先する。商品種別は主にストレージ系の統一テーマ。容器内アイテムは**出撃開始時にID/品質を封印**し、選択・回収・保存・再読込のルールはR5.12を維持。
- 床と壁は専用の軽量Canvas描画システムで表示。金属壁・床タイル・メンテナンス通路・区画番号・パレット・擦り傷・奥地警告表示を統一したキットから生成。見えている区画だけ描画して処理を抑える。現段階ではベクター風のゲーム内描画で、描き込まれた背景用テクスチャや専用家具イラストは未制作。

## 帰還の難しさと操作補助
- 出発と基本脱出は同じ場所で、深部から帰る必要がある。
- 1本道にならないよう、47本の連結辺に少数の追加経路をつなぐ方式。迷路の最遠区画まで長い経路を要求する。
- 敵は壁に向かって直進し続けないよう、現在の区画から目標区画までのグラフ経由で開口部を経由する暫定誘導を追加。大人数戦、複雑な回避、細かい環境障害物を含めた完全なAI経路探索ではない。
- 一時停止メニューから **踏査記録（訪れた区画だけの簡易地図）** を確認可能。現在地と出口を表示し、未踏査の通路や戦利品は非表示。読図中は戦闘も時間も停止。
- スマホ画面をボタンで埋めないよう、地図は一時停止メニューの内部に配置。

## 旧セーブ保護と制限時間
- R5.13の新規出撃だけ `mapVersion:3`。保存は `v:1` を維持し、`containers`（80地点）、`elapsedSeconds` と `visitedRooms` を追加。
- R5.12の途中セーブ（`mapVersion:2`）は旧2000×1600の定義で、元の920×720の旧エリアと旧途中セーブは旧定義でそれぞれ復帰。
- **制限時間は未決定**。新しい巨大迷路を試す間は時間切れなし。旧マップの暫定4分制限は変更しない。
- 戦闘・バッグ重量・安全ポーチ・持込装備ロストルールと市場/ガチャ/遊技場の処理は変更しない。

## 検証・未実施
- `tests/exploration-labyrinth.test.cjs` で 10項目の模擬回帰テスト。新旧マップセーブ、到達可能性、80個の封印中身、回収中停止、訪問済み地図、旧マップ互換を検査。
- レイアウトグラフ48区画が連結、全144回収候補へ12px半径のプレイヤーが移動可能（20px刻みのグリッド探索）。
- `tests/exploration-mall.test.cjs` と以前の装備・戦闘回帰テストも維持。
- **未実施**：iPhone Safari実機による操作確認、公開GitHub Pages実ブラウザでの周回E2E、FPS実測、すべての敵からの長距離経路到達・アート品質の最終確認。

## 次工程の推奨
1. iPhoneで最初の3〜5区画と裏通路の操作性を確認し、ドア幅・当たり判定・方向感覚を調整。
2. 同一テーマで物理的な棚・障害物を追加し、敵のルーティングとともに厳密な衝突・経路検証を導入。
3. 深部の警戒とリターンの駆け引きを強化するため、開錠・片側から開く保守扉・任意の遠回り脱出の設計を検討。
4. 制限時間は今回のマップの巡回時間を測定してから決定。80回収地点すべてを毎回周ることは想定しない。
