# R5.81 — 屋内施設V5／資材倉庫の改修用アート設計

## 目的とR5.81の範囲

2026-11-02に確認されたiPhone Safariスクリーンショットでは、倉庫の床のタイル模様・プログラムで描いた棚／パレット・区画ステンシル・追加Kenneyアートが重複し、通路と家具の判別が難しい状態だった。

**R5.81は新しい完成アートではなく、Tiledを正本とする「余計な重ね描きを外した比較用ベース」の整備。**
- 通常URL：`?v=R5.81` → 資材倉庫のJavaScriptによる床模様、巨大な床文字、代替パレット／バーコード表示、Kenney描画を停止。元からTiledにあるタイルと家具は残す。
- R5.80比較用：`?v=R5.81&mapArt=legacy` → 以前の床模様＋Kenney追加描画＋床ステンシル＋仮パレットを復元。
- 素材なし比較用：`?v=R5.81&mapArt=legacy&warehouseArt=0` → R5.80でKenneyだけ無効だった場合の見た目。
- 全て描画モードのみで、**地形データ・当たり判定・敵の視線判定・Loot・セーブ・シナリオ・両マップ表示は同一**。切替のために出撃中セーブを消さない。
- 素材の権利と来源：`maps/indoor/art/KENNEY_CC0_LICENSE.md`。PNGを削除せず比較用に保持する。

## 既存Tiledマップの確定データ（変更前ベース）

- 正本：`maps/indoor/indoor.tmj`（48列×38行、タイル16×16px、Tiled座標）
- 現行タイルセット：`maps/indoor/tiles/warehouse.tsj`（8列×12行、96タイル、うち43タイルがsolid）
- 資材倉庫の `theme-zone`：`x=544, y=288, width=208, height=176`
- 対象範囲：タイル `x=34..46, y=18..28` の13×11＝143セル
- 倉庫内に重なる既存レイヤーの実数：`Floor` 132 / `Patina` 20 / `Scars` 14 / `Walls` 19 / `Furniture` 9 / `SetDressing` 11
- 既存の `theme-prop`：パレット２個（584,357）（706,416）、バーコード１個（668,357）。これらはR5.81標準表示ではJavaScriptの仮絵を描かない。将来のTiledスプライト実装時に元の位置を参照する。
- 施設全体の `Gameplay`：11か所の物資 / 9か所の敵ポスト / スタート / 脱出口 / カードキー / 金庫扉 / 非常ハッチ。いずれも保存して位置を動かさない。

## 倉庫完成版に向けたビジュアルルール

1. **同じピクセル密度と視点**：16×16px、真上に近い見下ろし。ソフトなブラシ塗り・アイソメ絵・巨大な単体PNGを混ぜない。
2. **床は静かに**：床の基礎は2種類以下、汚れやひびは意図した箇所のみ、連続する床文字や全タイルの縁取りは禁止。天井照明の色は床にのみ自然に乗る。
3. **壁・出入口が先**：背の高い壁、内角・外角、扉枠、敷居、通行ルートをまずTiledで確定。棚で通路を後から塞がない。
4. **家具は機能と一致**：物流ラック、木箱、パレット、保管箱、台車、作業台は統一スプライトで組み合わせる。実際の足元が通行不可ならTiledの判定にも追加。飾りの上端は見た目だけ、足元判定は物理用に固定する。
5. **探索導線を優先**：主通路の初期案は3〜4タイル幅、棚間は2タイル幅を参考値とし、実際のプレイヤー半径12px、各敵半径、移動・索敵で検証。幅だけの判定で通行可能を主張しない。
6. **HUDと背景の情報量を分ける**：残時間・警戒・部屋名はゲームUI側にあるため、床の巨大な `INVENTORY / W-06` などは不要。現実の小さな看板を壁に置くのは許可。
7. **遮蔽は体験の核**：見た目・`solidAt`・敵の視線レイが同期。遮蔽物の見た目を作る前に実際の足元セルと視線を定義する。
8. **スマホ最優先**：画面幅360/390/430px、左右仮想スティック＋攻撃を保持。暗い場所でも操作の対象が読めること。

## アセット採用／制作ルール

- まずKenney CC0の16px素材から、**実際の完成絵に使うタイルを手動で選別**する。
- 床・壁・棚・木箱・設備の色温度、輪郭、投影方向を統一する。既存 `warehouse.png` の絵柄との差が大きければ必要な部分は加工または自作する。
- **一枚の統合タイルセット**に採用素材を登録し、ファイルごとにソースURL、ライセンス、変更内容、作者クレジットを記録する。
- TiledのタイルIDと `solid` プロパティは意味を持つため、既存IDの並び替え／上書きは厳禁。追加IDで作成してから小さな区画でテストする。
- 現行 `tiled-runtime.js` は外部タイルセット1枚前提。複数タイルセットのサポートは別工程で実装するか、単一の統合アトラスを使う。
- `?mapArt=legacy` の古い実装はレビュー完了まで削除せず、成功した新デザインと比較する。

## R5.81レビューで確認すること

1. 現行 `R5.81` と `mapArt=legacy` で倉庫の床・文字・仮パレットが確実に違う。
2. 倉庫以外のTiled地形・絵柄・部屋文字はそのまま。
3. 倉庫の通行不可部分、棚間移動、隠密、ガードの追跡が変わらない。
4. 出撃前マップと探索中マップが一致し、途中復帰でも封印報酬が不変。
5. 実機Safariで倉庫に到達しスクリーンショット比較し、R5.83制作に進めるか判断する。
