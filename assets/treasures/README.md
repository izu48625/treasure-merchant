# 財宝画像の高解像度化

現在の20種類の財宝画像はすべて256×256pxのWebPで、index.htmlに埋め込まれている。現状は高精細画像の登録なし。

新しい高精細画像が完成したら、assets/treasures/large/ITM-xxxxx.webp として配置し、gacha-ui.js内の TREASURE_DETAIL_ASSETS に実在するパスを登録する。

鑑定の単体結果だけ高精細画像を使い、10連・50連一覧や所持品は既存の軽量画像を使う。高精細画像が表示できない場合は既存画像へフォールバックする。

単純な拡大補間は画質改善として数えない。アイテムの名称・分類を守り、元画像以上の細部を持つ真正の新規画像を768〜1024px程度で制作してから導入する。

抽選・品質・レアリティ・セーブデータは画像に依存させない。
